# 汇总完整材料

主论文和补充材料已经逐页保存全文、图源、发现和证据。结合所有已保存 Claim/Evidence 整理研究设计和固定主题的文章故事，保留跨文件关系，不按汇报篇幅筛选。

已有 Claim/Evidence 是完整底稿，由程序保留；本步骤只返回 metadata、studyProfile 和 story，不重新创建或删除发现，不替换已有 ID。引用已有 Claim ID 或 Evidence 中的 Source ID；未知主题保持空数组，不编造来源。story 是主题综合，每个有依据的主题通常保留 1–3 个综合点，合并相同结论，保留不可合并的关键组别差异、方向、定量结果、冲突和限制；不逐条复述已保存的 Claim/Evidence，也不机械罗列全部引用。完整性由底稿保留保证，不以汇总的篇幅重复底稿。

研究设计摘要应涵盖理解主要结论所需的样本、组别、物种、模态或终点。科学强度不能超过原始证据，分别陈述实验观察、作者解释和限制。逐条复核因果动作的主语、对象、否定和比较方向；“突变使药物失效/阻断药物敏感性”不能压缩为“突变阻断被测过程”。若两种叙述看似冲突，保留原始完整条件，不用更简短但方向改变的句子。来源角色、论文图号与汇报主线/补充不同。`kind` 标签只是辅助；依据证据正文识别前人工作、二级综合判断与本文直接实验。前人研究中的基因/队列/干预不能因被讨论或引用而列入本文研究设计或机制验证；只在 studyProfile/studyDesign 列入有明确本文方法或直接实验依据的项目。特定遗传背景或处理条件下的既往观察不得扩写为普遍机制或整个领域已知结论。

作者明确提出但尚未解释的核心机制、相互竞争的解释和测量限制，须在 limitations 或 knowledgeGap 中保留各自具体内容，即使叶子批次将其放在 question/conclusion。合并时先核对这些未解决问题，再综合主要结果；不能用泛泛“尚需研究”替代具体未知，也不能将未解释关系写成已证明的机制。正文与图注的不一致保留原有标注，不合成连续范围。输出前对照 mainFindings 和 conclusion，确认同一干预、方向、数字、背景条件没有相互矛盾；已被后续批次明确解决的局部“本批未见”不得保留为全文未知。每个综合点只附足以支持该点的必要引用，通常 1–3 条；不把相似点及其全部 ID 机械拼接。`studyProfile` 用一段概括设计，避免重复整段方法。输出以中文为主，保留必要专业名称和准确条件。`story` 各主题均为综合，全部主题合计建议不超过 20 点，真正独立的必要限制可额外保留。

原标题和论文元数据以主论文首页及已有元数据为依据，不用补充材料封面或文件名替换。汇报要求不改变本步骤的全文范围，也不要求一个故事主题对应一页幻灯片。
