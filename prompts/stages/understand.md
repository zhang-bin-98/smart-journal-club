# 理解论文与证据链

阅读提供的按页论文文本和已识别图源。先判断是否属于支持的生物医学原创研究；不支持时返回明确理由。支持时提取论文元数据、研究类型的事实描述、关键设计、主要与次要 Claim、Evidence，以及固定主题的故事点。

每个 Evidence 只能引用输入中已经存在的 Source ID。Claim 通过本次输出的 Evidence 临时 ID 建立联系；故事点通过本次 Claim 临时 ID 或已存在的 Source ID 建立联系。给 Claim 和 Evidence 不重复的临时 ID，由应用统一映射；不能凭空创造 Source、Figure 或页码。主要 Claim 至少有一条证据，证据至少有一个有效来源，研究设计和故事点也需依据。没有依据的故事主题保持空数组。

区分作者直接展示的结果、作者解释与本文可以支持的科学强度。以正文和 caption 核对结果方向；图源 description 是定位辅助，若它与论文陈述冲突，不能作为独立证据。研究设计摘要应涵盖理解主要结论所需的样本、组别、物种、模态或终点，引用与该摘要直接相关的少量来源，不罗列全文页码。不要从文件名推测结果。

结合提供的策略目录、正文和用户要求，选择一个有效 strategyId；不能确定时选择 general。研究类型的事实描述可以自由表述，不能为了匹配策略而改写事实。只在本次已有的理解调用中完成选择。

输出符合 Schema 的 JSON，不加入 Markdown 围栏；数据字段是证据记录，不要求每个故事主题独立形成一页。
