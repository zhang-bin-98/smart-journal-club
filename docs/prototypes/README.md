# HTML 交互原型

| 页面 | 文件 | 状态与规格 |
|---|---|---|
| 项目管理与新建 | [projects.html](projects.html) | 用户确认页面可行，包含新建双 PDF、阶段进度与存储概览；[页面规格](../ui/项目准备.md) |
| 模型配置 | [model-settings.html](model-settings.html) | Responses 独立配置页讨论稿；[页面规格](../ui/模型配置.md) |
| 论文分析与图源页查漏 | [paper-analysis.html](paper-analysis.html) | 用户确认当前分析页无需修改，不增加文章类型确认；[页面规格](../ui/论文分析.md) |
| 论文图源与 Figure 切分核对 | [figure-review.html](figure-review.html) | 用户确认页面可行；[唯一页面规格](../ui/图源核对.md) |
| 大纲与演讲稿 | [outline-speech.html](outline-speech.html) | 用户确认页面可行；[唯一页面规格](../ui/大纲与演讲稿.md) |
| 幻灯片 | [slides.html](slides.html) | 用户确认页面可行，包含检查 Tab 与导出门槛；[页面规格](../ui/幻灯片与检查.md) |

直接在桌面浏览器打开 HTML，无安装、构建或外部资源依赖。图源页可连续滚动、修框/补删/改标签、调整图注关联、拖动侧栏；本地保存与生成流程均为演示行为。图源页首次默认左导航 176px，余下空间中栏/右栏 5∶4，拖动后记住偏好，双击分隔线复位。

大纲页左导航 224px，中右栏默认 5∶4；支持连续章节、拖动调序、拆合讲述、图源多选及反向讲述定位。四步导航组在各工作台均居中；大纲页下一步打开幻灯片固定草案，不生成真实 PPT，各页的示例编辑独立保存。

幻灯片页底部可展开 AI 输入，右栏展示对话与修改预览；支持范围选择、提问/修改、取消、应用/放弃与整次撤销。当前仅以固定规则演示图组排列、间距和屏幕文字精简；提问返回范围摘要，不调用真实模型。

检查已合并到幻灯片右栏的独立标签，顶部不另放检查按钮：筛选问题并定位当前画布，随编辑更新；顶栏直接导出，自动执行必要校验。可演示页面放不下、必需图源故障、修复、撤销和取消导出；用户主动弃图与覆盖变化仅提醒；不生成真实 PPTX。旧 check-export.html 仅跳转到幻灯片检查面板，不再作为独立检查页。

图、图注、译文和正文都是合成示意数据，不能用来评价真实切分算法或科研内容。图源页在已确认稿基础上同步公共导航与分步入口，大纲页保存已确认交互稿；全部原型均为设计资产，不接入生产入口、构建或 Pages/PWA 发布配置。不要把它的内联脚本、localStorage、示例标签或模拟进度当作未来应用架构。

四个工作台页面已确认，已确认项目管理稿支持一主一补 PDF 准备、保存记录、模拟分析和项目列表管理、四段式阶段进度条（不表示耗时百分比）；仅持久化文件信息，不保存真实 PDF，具体布局已确认。论文分析页左栏可直接编辑汇报要求并自动保存；与项目新建共用要求，不因修改重新分析。页面提供双文件全部页缩略图、页数进度、人工加入/排除及恢复自动、暂停/继续、模拟限流/失败与手动下一步。项目启动跳转到该页，分析完成不自动进入图源核对；各页图像均为固定合成数据，补选不改变另一原型的 Figure 内容。独立 HTML 跳转/刷新停止模拟计时，继续需手动启动；不代表正式应用会因普通视图切换取消任务。修改时同步实际受影响的页面规格与所属里程碑记录。[返回文档入口](../README.md)。

项目管理页增加存储概览：默认展示明确标注的示例占用、配额与全部项目 PDF 文件信息；可切换接近上限、不可用示例，或主动读取当前来源的浏览器存储估算。读取为只读操作，不申请持久化权限、不自动清理；原型不保存 PDF 内容。

模型配置原型为独立全局页面，提供 Base URL、模型 ID、示例 Key 和思考强度（默认跟随服务），固定 Responses API。项目管理与新建的入口直接进入配置；返回恢复新建示例文件信息/名称/要求，不保存真实 PDF。配置非秘密字段和 hasKey 演示标志存于专用原型记录；不接受真实 Key、不发请求，连接与逐项能力检查均为模拟。思考强度不支持时显式恢复默认，结果不会自动降档。
