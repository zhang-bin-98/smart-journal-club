# HTML 交互原型

| 页面 | 文件 | 状态与规格 |
|---|---|---|
| 项目管理与新建 | [projects.html](projects.html) | 新建弹窗及双 PDF 范围已确认，具体交互待确认；[页面规格](../ui/项目准备.md) |
| 论文图源与 Figure 切分核对 | [figure-review.html](figure-review.html) | 用户确认页面可行；[唯一页面规格](../ui/图源核对.md) |
| 大纲与演讲稿 | [outline-speech.html](outline-speech.html) | 用户确认页面可行；[唯一页面规格](../ui/大纲与演讲稿.md) |
| 幻灯片 | [slides.html](slides.html) | 用户确认页面可行，包含检查 Tab 与导出门槛；[页面规格](../ui/幻灯片与检查.md) |

直接在桌面浏览器打开 HTML，无安装、构建或外部资源依赖。图源页可连续滚动、修框/补删/改标签、调整图注关联、拖动侧栏；本地保存与生成流程均为演示行为。图源页首次默认左导航 176px，余下空间中栏/右栏 5∶4，拖动后记住偏好，双击分隔线复位。

大纲页左导航 224px，中右栏默认 5∶4；支持连续章节、拖动调序、拆合讲述、图源多选及反向讲述定位。导航组在三页均居中；大纲页下一步打开幻灯片固定草案，不生成真实 PPT，各页的示例编辑独立保存。

幻灯片页底部可展开 AI 输入，右栏展示对话与修改预览；支持范围选择、提问/修改、取消、应用/放弃与整次撤销。当前仅以固定规则演示图组排列、间距和屏幕文字精简；提问返回范围摘要，不调用真实模型。

检查已合并到幻灯片右栏的独立标签，顶部不另放检查按钮：筛选问题并定位当前画布，随编辑更新；顶栏直接导出，自动执行必要校验。可演示页面放不下、必需图源故障、修复、撤销和取消导出；用户主动弃图与覆盖变化仅提醒；不生成真实 PPTX。旧 check-export.html 仅跳转到幻灯片检查面板，不再作为第四页。

图、图注、译文和正文都是合成示意数据，不能用来评价真实切分算法或科研内容。图源页在已确认稿基础上同步公共导航与分步入口，大纲页保存已确认交互稿；四个有效页面均为设计资产，不接入生产入口、构建或 Pages/PWA 发布配置。不要把它的内联脚本、localStorage、示例标签或模拟进度当作未来应用架构。

三个工作台页面已确认，新增项目管理讨论稿支持一主一补 PDF 准备、保存记录、模拟分析和项目列表管理、三段式阶段进度条（不表示耗时百分比）；仅持久化文件信息，不保存真实 PDF，具体布局待确认。后续页面经用户授权后再加入对应原型；不预建空文件。修改时同步实际受影响的页面规格与所属里程碑记录。[返回文档入口](../README.md)。
