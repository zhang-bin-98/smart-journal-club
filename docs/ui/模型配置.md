# 模型配置

> v0.5 公共 UI 设计；[HTML 原型](../prototypes/model-settings.html) 待用户确认。已有设置能力不等于本原型已实施。项目管理及四步工作台保持已确认稿。

## 入口与布局

从项目管理顶栏、工作台更多菜单、缺少配置提示打开同一个全局弹窗，不属于四步流程。桌面固定宽度，标题/关闭、表单、结果反馈和底部操作保持清楚；保存或关闭返回原位置，保留原页选择、滚动及未完成的新建项目输入。独立 HTML 仅为讨论载体，不将模型配置改成第五个页面步骤。

```text
┌──────────────────────────────────────────────────────────────┐
│ 模型配置 · 当前浏览器全部项目                           [关闭] │
├──────────────────────────────────────┬───────────────────────┤
│ 模型 [已验证候选                  ▾] │ 配置与数据            │
│ API Key [••••••••••••••••] [显示]   │ 文本/图片发送对象     │
│ [测试连接] [取消测试]                │ Key 保存/清除范围     │
│ 连接结果 / 保存失败恢复              │ 离线/任务运行中说明   │
├──────────────────────────────────────┴───────────────────────┤
│ [清除已保存 Key]                            [取消] [保存]    │
└──────────────────────────────────────────────────────────────┘
```

## 字段与操作

| 控件 | 行为 |
|---|---|
| 模型 | 仅列仓库已完成浏览器验证的固定候选；现有 M0 记录只通过 DeepSeek，GLM 未验证不出现在可选项。不增加任意模型、Base URL 或按任务混合路由 |
| API Key | 正式应用可输入，默认遮蔽，支持显示/隐藏；草稿仅在弹窗内，修改使上次测试结果失效。原型用只读示例代替真实输入 |
| 测试连接 | 对当前草稿显式发起最小请求，不带项目论文或自动保存 Key；测试中防重复，支持取消。成功仅说明本次连接成功，不承诺后续额度或所有能力；不强制先测试才能保存 |
| 保存 | 显式提交模型与 Key，成功关闭并返回原页；失败保留草稿、原配置不变并允许重试。不会自动启动或续跑论文任务 |
| 清除 Key | 单独清除已保存密钥，成功返回原页；保留项目、模型选择和论文成果，失败保留原配置。运行中不可清除 |
| 关闭 / Esc | 丢弃未保存设置输入，取消当前连接检查，迟到结果不回填；保存提交过程中暂不关闭，避免误报结果 |

弹窗说明：配置对当前浏览器全部项目生效；分析所需文本与图片直接发送给所选供应商，Key 在当前浏览器保存且可单独清除。Key 不进入项目、日志、模型内容或导出。不得将测试状态、遮蔽文本或原型演示标志当作真实凭据。

## 状态与恢复

- 未配置可关闭返回，本地浏览/编辑和资源完整时的导出保持可用。
- 离线禁用测试，仍允许保存和清除；认证失败提示检查 Key，限流提示稍后测试，网络失败提示网络或浏览器连接限制。展示简明可操作原因，不展示供应商错误体。
- 存在运行中的模型任务时可查看设置，但禁用更改、保存、清除和连接测试；提示返回任务等待完成或取消。弹窗不擅自取消论文任务，也不提供另一套任务控制器。
- 保存、清除由应用统一入口核对任务状态及写入结果，不能仅靠按钮禁用保护；连接请求经共享调度器且可取消。读取配置和结果不增加 Paper/Deck revision，契约边界见[模型与部署](../architecture/模型与部署.md)和[并发调度](../architecture/并发与任务调度.md)。
- 原型附有独立标注的场景控件，演示成功、认证失败、限流、网络失败、离线、保存失败、任务运行中；这些控件不会进入正式产品。只保存演示布尔值，不收集、持久化或发送真实密钥。
