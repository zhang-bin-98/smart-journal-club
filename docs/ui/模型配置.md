# 模型配置

> v0.5 目标设计；用户确认独立配置页面、通用 Responses API、Base URL、模型 ID 与思考强度。当前 [HTML 原型](../prototypes/model-settings.html) 的页面布局与交互已获用户确认，正式应用尚未接入。

## 入口与布局

项目管理顶栏、工作台更多菜单和缺少配置提示进入同一个全局配置页，不占论文处理的四个步骤。桌面固定工作区：顶部标题、保存状态、返回和“保存并返回”；中部左侧表单、右侧能力结果/生效范围；内容内部滚动，原型底部场景控件不进入产品。没有打开设置的启动页或设置弹窗。

```text
┌──────────────────────────────────────────────────────────────┐
│ 模型配置 · 保存状态                     [返回] [保存并返回]   │
├──────────────────────────────────────┬───────────────────────┤
│ 连接配置              Responses API │ 连接 / 能力检查结果   │
│ Base URL [                        ] │ 图片、工具、结构化    │
│ 请求地址预览                        │ 结果、流式返回        │
│ API Key [••••••••••••••••] [显示]   ├───────────────────────┤
│ 模型 ID [                         ] │ 全局生效与数据去向    │
│ 思考强度 [服务默认               ▾] │ 运行中 / 离线说明     │
│ [测试连接] [检查应用所需能力]        │                       │
│ 结果 / 恢复建议                     │                       │
│ [清除已保存 Key] [恢复已保存配置]    │                       │
└──────────────────────────────────────┴───────────────────────┘
```

## 字段与操作

| 控件 | 行为 |
|---|---|
| Base URL | 可填写服务 API 根地址，保留自定义路径，去掉尾斜杠；粘贴以 /responses 结尾的地址时归一化根路径，预览最终地址。无效协议、嵌入账号、查询参数或片段拒绝保存/测试，不能丢失路径或拼出重复 /responses |
| API Key | 正式应用允许输入，默认遮蔽、显示/隐藏、可单独清除。原型只提供示例密钥开关，不接受真实 Key |
| 模型 ID | 手动填写当前服务的模型名称，不限制 DeepSeek/GLM，不自动拉模型列表 |
| 思考强度 | 默认“服务默认”，不发送强度参数；候选档位按已知模型能力展示。未知服务/模型标“待验证”，不能将所有档位称为通用支持。测试使用当前档位，不支持时显式提示改回默认，不静默忽略、降档或重试另一档位 |
| 协议 | 固定 Responses API，非可选协议；不维护 Chat Completions 自动回退或按步骤混合路由 |
| 测试连接 | 使用当前草稿的小请求，不带论文、不保存配置；只证明本次连接结果，不等于完整能力通过 |
| 检查应用所需能力 | 独立显式操作，检查当前配置的图片输入、工具调用、结构化结果和流式返回，展示逐项通过/失败/未检查，不以返回普通文本冒充全通过；用最小固定素材，不使用项目论文 |
| 保存并返回 | 一次保存地址、Key、模型和思考强度并返回来源；允许先保存未测试配置，失败保留草稿和旧配置，不自动开始/继续任务 |
| 清除已保存 Key | 只清除保存的 Key，保留保存的地址、模型和强度及项目成果；成功恢复保存配置并留在本页，不将其他未保存字段顺便提交；失败保留原配置与草稿 |
| 返回 / 恢复已保存配置 | 返回丢弃未保存设置并取消检查；恢复只重置当前页输入。不将 Esc 沿用为关闭页面。保存提交期间暂不返回 |

提示说明较高思考强度可能增加时间和费用，不保证质量更好。全部设置全局生效，改动只影响后续请求，不重新解析论文或改写已有稿。文本与图片发送到用户填写的服务地址，不写死供应商；Key 不进项目、日志、上下文或导出。

## 导航与状态保护

- 返回目标由应用记录内部来源路由及项目身份，不接受任意外部跳转；保存/返回都恢复来源选择、滚动与新建草稿。正式 SPA 新建文件 Blob 保留在所属创建会话，不能只保留文件名就宣称真实文件仍可用；若文件丢失必须要求重新选择，不能创建无资源项目。
- 原型从项目管理/新建入口直接进入此页；新建返回仅恢复示例文件信息、名称和要求，原型不存 PDF 内容。独立 HTML 的跨页执行不是正式 SPA 任务生命周期验证。
- 离线禁用两种检查，仍允许保存/清除；任务运行中可查看配置但禁用变更、检查与保存，提示回任务等待完成或取消，不在此自动取消论文任务。
- 配置任一字段变化使旧检查结果失效；检查取消/离开/新任务后迟到响应不回填。读取、检查与显示结果不改变 Paper/Deck revision；应用命令在保存前复核全局任务状态，不能只靠 UI 禁用。
- 检查经过统一请求调度器，错误分类与恢复沿公共契约。档位及参数映射、URL 与配置字段唯一约束见[数据模型](../architecture/数据模型.md)和[模型与部署](../architecture/模型与部署.md)。
- 原型只保存非秘密配置和 hasKey 演示标志，测试为固定结果；不存在真实 API、真实 Key 或自动发送。提供不支持强度/图片、离线、运行中、保存失败等场景，用于讨论交互。
