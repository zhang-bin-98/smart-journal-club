# 论文分析与图源页查漏

> v0.5 目标设计，尚未实施。四步拆分、页级查漏及手动进入下一步已确认；[HTML 原型](../prototypes/paper-analysis.html) 的具体布局用于继续讨论。

## 页面职责

第一步完成主论文及可选补充材料的全文解析、图源发现、自动 Figure/Panel 切分与全文证据整理，展示当前进度，允许用户查看全部页面以发现漏掉的图源页。第二步才核对具体整图/Panel 边框与关联。页级选择表示是否需要图源处理，不代表正文提取范围或 PPT 取舍，也不是要求用户逐页核对。

## 桌面布局与操作

| 区域 | 内容 |
|---|---|
| 顶部 | 四步居中导航；当前任务状态；开始/继续/暂停；就绪后主操作“下一步：图源核对” |
| 左栏 | 全部材料/主论文/补充材料；每文件文本提取、图页发现的已完成/总页数；图源处理数量、证据整理状态、已用时间 |
| 中栏 | 默认全部页缩略图，按文件分组连续滚动；显示文件内页码、“待分析 / 自动发现 / 未发现 / 人工加入 / 人工排除”和处理状态；可筛选图源页、未入选页、待处理页 |
| 右栏 | 当前页放大预览，文件身份、自动结果、人工选择和处理说明；快捷勾选“作为图源页处理”，可恢复自动选择 |
| 底部 | 自动发现、人工补选、待处理数量与保存反馈；原型演示入口不进入正式产品 |

缩略图支持点击定位和直接勾选，复选框不能触发重复选择；补选后保持滚动位置和筛选。未发现页仍可见，未分析不能标成无图。无匹配给清除筛选入口；无补充材料不展示假文件。全部页仅表示可浏览范围，实际实现按可见范围加载缩略图，不一次渲染全部高清图。

## 进度与手动下一步

- 文本提取、图页发现按文件分别显示页数；图源分析按待处理页/图单元显示数量，不能将文字提取完成等同于整篇分析完成。总量未知时显示正在执行的步骤；不展示虚构剩余时间、综合百分比或“全文已理解 100%”。
- 模型限流等待明确显示正在等待服务恢复，已用时间继续计入；结束等待不增加完成数。失败定位文件与页，重试保留有效结果；取消/暂停立即停止后续派发，迟到结果不可生效。
- 分析完成必须留在本页，按钮变为“下一步：图源核对”。用户不必逐页打勾或填写确认表；必须主动点击按钮或就绪的下一步导航，浏览次数不作为通过条件。
- 所有文件的必需分析完成、有效图源页处理完成、关联刷新完成且保存成功后，才允许进入图源核对。补选待处理、失败、取消后的未完成工作或保存失败均显示具体原因；不能通过导航绕过门槛。
- 返回列表或已有视图属于浏览，不取消正式应用内运行任务；刷新/关闭仍中断任务，恢复只读成果并等待用户继续，不建设后台服务。

## 人工补选与结果保护

- 有效图源页集合来自自动结果加人工覆盖。人工选择优先，运行中的晚到自动结果不得覆盖；取消人工覆盖才回到最新自动选择。
- 在正在运行的分析步骤内补选，系统自动加入受限队列；分析就绪后补选即授权该页必要的局部处理与关联刷新，无需第二次点击开始。显式暂停/取消后补选仅保存待处理项，必须用户继续，不能复活已取消任务。
- 局部处理保留其他页与人工 Panel。取消尚未产生图源的页可直接撤回任务；取消已产生图源/引用的页先预览实际影响，再显式应用，受影响引用需修复后才可就绪。不是悄悄删图，也不是删掉正文。
- 页面和 Figure 不一一对应；一个页面可包含多个 Figure，跨页图像与图注仍按来源关系关联。图注页不因没有整图自动失去全文解析资格。
- 补选改变工作底稿时，沿冻结 Paper、旧稿保护和整体图源确认失效规则处理。用户进入第二步不是确认算法准确，更不代表科研结论已验证。

## 原型边界

提供合成主论文与补充页，包含一张可人工补选的漏检示例和可纠正的误检示例；支持逐页模拟进度、暂停/继续、补选、影响确认、错误/限流状态和手动下一步。文件名可来自项目管理示例，页数及图像始终是合成数据，不读取上传 PDF、不调用模型、不建立真实 Worker 池。

仅保存示例选择与已完成模拟单元；刷新和独立 HTML 跳转停止计时，不自动续跑。图源核对仍为独立固定示例，不宣称本页补选结果已传入真实切分数据。正式跨视图任务与进度通过应用会话共享，不能照搬原型 localStorage 与计时器实现。
