> v0.5 规格，实际交付与验收状态以执行目录为准；图源、大纲与讲稿、幻灯片三页 HTML 已获用户确认。本轮确认包括右栏检查 Tab、必须修复项阻断下载、主动弃图与覆盖变化仅提醒；独立检查步骤已取消；当前实施状态见 [执行目录](../execution/README.md)。

### 3.6 幻灯片编辑工作区

#### 分页与图组的职责

用户从大纲与讲稿点击下一步后，系统依据完整讲述及多对多 Panel 证据自动建议页面边界、图组和版式并制作草案；完成后停在幻灯片工作台。分页不提前放在大纲页，也不把一段讲稿固定成一页。

支持一段跨多页、多段合一页、同一 Panel 跨页复用。分页只改变片段分配，保留大纲段落身份与原文顺序；跨章合页保留各段落原章节，页面归属与讲述归属分别维护。按完整句意分配讲述，页面始终可追溯到相应讲稿；分配与备注不重复整段、不漏句。用户能调整页边界、拆页、合页和重排，操作同时维护关联，一次 Undo 恢复。删页保留论文事实和讲稿内容，对未分配内容显示待安排，不把删页自动解释成省略论文发现。

多个 Panel 服务同一结论时先建议同页图组；内容过密则按讲述层次分多页，不以缩小到不可读换取一页。图组提供多选 Panel、自动排列、组内顺序/大小/间距调整，每个 Panel 仍是独立引用和可编辑图像，不烘焙成失去来源的拼接位图。复用已有 panel-grid/two-figures 和共享几何；除规则排列外支持常见矩形分区，例如左侧 A/B 上下排列、右侧 C 通高。预设选择后可拖分隔线调整比例，右栏提供比例/间距输入及顺序按钮，作为拖动的替代；一次拖动结束保存一次并可撤销。持久化与算法边界见[图组布局契约](../architecture/图源与渲染.md)，不扩展通用自由画布。

图组可跨 Figure 选 Panel，包括已上传补充 PDF 中的附图；保留原图号与 Panel 标签，来源不随位置变化。附图身份独立于汇报主线/补充标签，可提前用于主线，同图可再次解释。用户不需要重找内容或维护来源数组。

本页讲稿编辑保存后，备注从同一正文自动派生；分页、合页、移讲述等确定性操作同时维护分配与备注，一次操作一次 Undo。页面标题、正文和图组按明确手工操作或用户应用的候选更新，不能仅因讲稿改过就后台改写。结论或 Panel 关系变化提供页面更新提醒，用户请求后生成候选；人工内容先预览再应用。点击检查在当前工作台展开问题列表并定位现有画布，不跳转独立页面，不隐式导出或重新生成。

#### 画布与直接编辑

```text
┌────────────────────────────────────────────────────────────────────┐
│ 项目名 · 已保存           [幻灯片]                   [导出 PPTX] │
├──────────────┬──────────────────────────────┬──────────────────────┤
│ 主线 / 补充  │ 当前 Slide Canvas            │ 内容 / 图源 / 版式   │
│ ▾ 章节 3 页  │ 16:9，适配剩余空间           │ AI 对话 / 提案       │
│   05 缩略图  │ 选中图：[来源][裁图][删除]   │ 本页目的 / 结论      │
│   06 已选中  ├──────────────────────────────┤ 发现 / 来源 / 版式   │
│ ＋新增 / 删除│ 当前页讲稿（调高 / 收起）    │                      │
├──────────────┴──────────────────────────────┴──────────────────────┤
│ 当前页与进度     [展开 AI 输入：范围 / 提问或修改 / 输入 / 发送] │
└────────────────────────────────────────────────────────────────────┘
```

| 区域 | 控件与行为 |
|---|---|
| 顶栏 | 沿用[工作台外壳](../ui/工作台与公共交互.md)两行外壳；当前主操作与导出可见，低频操作进更多菜单 |
| 章节导航 | 主线/补充标记、章节折叠、页数、缩略图、编号、选中态；单选/多选、拖动重排、新增与删除 |
| 中央画布 | 默认连续滚动，目录、底部讲稿与右栏跟随当前页；可切换专注当前页，返回连续列表。缩放仅改变查看比例；点击文字编辑，选中元素有操作，不提供整页任意元素的自由坐标手柄；图组内使用有限调整控件 |
| 讲稿面板 | 当前页讲述内容；与页面选择同步，可独立滚动、调高或收起，保存时维护对应关系 |
| 右侧 Inspector | 内容/图源/版式/AI 可切换、可收起；展示页目的、结论、来源、布局、图像操作或对话与提案 |
| 底部命令区 | 固定紧凑状态条与可展开 AI 输入；实际范围、模式和发送/取消始终在其区域内可达 |

AI 对话与输入共用一个 controller 和请求状态；右侧不再设第二输入框。切换标签、收起面板或浏览页面不扩大范围，也不发起新请求。无可用 Undo/Redo 时禁用按钮；持续显示当前页/总页数。

- 新增页使用文字布局，标题和空文字可编辑；占位提示不写入导出。保留换行、焦点、光标和输入法；编辑结束一次保存与撤销，不逐按键写历史。
- 删除页或元素可撤销，不逐次弹确认；允许多选删页和删空。系统维护章节、讲稿分配、来源与布局，不让用户为了删页修预算或补占位内容。叙事不足作为可定位提示，非法悬空引用不能写入。
- 零页显示“还没有幻灯片”和“新增页”，清除失效选择，保留 Undo/Redo，禁用导出。AI 不能把“这页”解析成不存在的目标。
- Figure 可查看来源、调整当前元素裁图或删除。单页裁图不修改论文底稿；修改论文切分明确进入图源工作区。
- 手工草稿使待提交的同范围 AI 修改失效并取消；单纯选择不取消。重复发送禁用。AI 的“撤销”只在对应修改仍在撤销栈顶时可用。
- 修改讲稿可请求更新相应页面，修改页面可请求调整讲稿；已有人工内容不被后台改写，差异应用是一笔可撤销操作。
- 整套重生成预填现有要求，复用相同分步流程准备候选，大纲/讲稿完成后等待用户进入幻灯片。成功并获准替换后切换版本；已有手工成果的替换先展示具体变化。候选存在期间 Current 可正常编辑，基准变化使候选过期，保留当前稿并提示重新生成候选。完整新稿候选保存后可跨刷新恢复，工作台提示“有一份新稿待查看”；可查看差异、应用或放弃，过期时只读并解释原因。再次生成中保留旧候选，新完整结果保存成功后才替换；不把工作计划或未保存的流式输出标为已保存新稿。

辅助面板由用户主动收起，中央画布使用释放的空间；不按窗口宽度自动转换为抽屉或纵向布局。底部命令区保持紧凑，桌面工作台的画布与主操作持续可见。

#### 编辑器的直接操作与 AI 辅助

默认选中上次查看页，首次生成选第一页；左侧缩略图不在中间内容区重复。中央页工具栏显示当前页标题/编号、布局、Undo/Redo、适配与讲稿开关。页面上的文字点击进入编辑，Figure 点击显示“来源 / 本页裁图 / 更换 / 删除”；不让用户先在巨大属性表中查找对应元素。更换图源只能选论文已有 Figure/Panel，不新增通用图片库。

右侧默认显示所选对象的内容或图证据，未选元素时显示页面属性；“AI”是并列标签，不默认占据全部屏幕。布局以六种带名称的小预览选择，不能显示 layoutId/JSON。页面新增、删除和重排同时有可见按钮及键盘替代；多选仅在缩略图导航中发生，删除前显示选中页数，删除后可撤销。

讲稿默认显示当前页文本与“编辑 / 收起”，高度有限且可调；长讲稿在面板内滚动，需要专注编辑时跳到大纲与演讲稿的对应段落。来源、讲稿、页面共享定位，避免在多个视图反复找同一发现。

底部 AI 输入默认折叠为紧凑入口，展开后显示范围、提问/修改、输入、发送/取消；输入框多行高度有上限并内部滚动。右侧只展示对话、进度、候选差异和应用/放弃，不设第二输入。局部提案注明“未应用建议仅本次会话保留”，刷新/关闭项目后丢弃；这与可恢复的完整新稿候选分开。提案预览固定列出受影响页和讲稿，选择前后版本只改变预览，不改当前稿；手工修改导致提案失效时保留解释并提供重新请求入口。

#### 已确认的幻灯片 HTML

[幻灯片 HTML](../prototypes/slides.html) 使用七页固定示例，首开选第二页演示图组。一段讲稿跨两页、多段讲稿同页、Panel 跨页复用均可检查；连续滚动/专注模式、右栏调宽、讲稿调高/收起、文字编辑、讲述移页、按句换页、合页、删页后重新安排、图源多选/排序/列宽/间距及 Undo/Redo 可操作。

初始左栏 200px、右栏 320px、讲稿区域高 210px，均为讨论稿尺寸。长目录拖动支持边缘自动滚动，并提供上移/下移；只调整页序保留章节与主线/补充标签。显式移动讲述段落才改变其章节；换页面章节或跨章合页不隐式迁移段落归属。合页保留前页标题、合并屏幕文字和讲稿、去重图源，不自动改写人工文字。

当前 HTML 的组图倍数控制列宽，网格同列共用；图像等比显示，不烘焙为单张位图。后续已确认采用分区预设和可调比例的方向；分隔线调整及不规则图组尚未补入本 HTML，不能以当前原型宣称这些交互已验证。分页初始保留独立图组引用供分别调整。当前 HTML 的版式、大小控件、讲述分配及 AI 交互已获用户确认；确认设计可行不等于应用已实现。

三页 HTML 独立保存示例状态：大纲页下一步打开固定页面草案，不把前页编辑实际生成 PPT，本页讲稿也不回写另一份 Demo；真实应用仍使用同一版本化内容契约。检查入口读取当前幻灯片示例状态，旧检查页地址仅跳转到本工作台，未实现模型生成、真实导出、PDF 裁图或真实 AI 修订。

原型已补齐底部“展开 AI 输入”和右栏 AI 对话。输入支持当前页、所选页面、整稿范围，以及提问/修改模式；发送后范围固定，浏览其他页不会改变待应用目标。新回复定位到差异；用户可应用、放弃或取消，应用作为一次 Undo 保存，手工编辑使旧建议失效。收起输入不丢本轮对话，刷新仅恢复已应用的页面编辑，不恢复请求或待应用建议。

当前使用明确标注的固定规则模拟：可试“把图改为上下排列，缩小间距”“改成两列网格”或“精简屏幕文字”。提问仅返回只读范围摘要；无法演示的自由要求会明确提示未执行。真实应用通过 AI 对话修改讲稿、分页和内容的范围仍按上文契约，不能以此 Demo 证明模型能力。

### 3.10 幻灯片内的检查与导出

检查是幻灯片工作台的一项功能，不占据独立步骤；完整导航为“论文分析 → 图源核对 → 大纲与演讲稿 → 幻灯片”。顶栏主操作为“导出 PPTX”，不另设检查按钮；右栏新增与图组、讲述分配、AI、页面并列的“检查”标签，有必须修复项时显示数量。用户无须进入专门的检查界面或逐项确认后才能导出。

| 内容 | 主要处理位置与行为 |
|---|---|
| Figure 切分、Panel 与图注关联 | 图源核对；后续发现问题可返回具体来源 |
| 发现覆盖、讲述逻辑、主线与补充 | 大纲与演讲稿随编辑更新；区分已识别发现的去向与原文提取/关联缺口 |
| 图组、页面边界、图源资源、讲稿分配 | 幻灯片编辑中更新，提示标在对应页；选中问题直接定位已有画布，右栏解释原因并提供操作 |
| 最终导出校验 | 点击导出时保存输入并核对当前稿件；通过即开始导出，必要问题才展开处理 |

检查标签复用右栏，可按全部/阻止导出/内容建议筛选；切换其他标签时保留画布、选择和讲稿位置。资源缺失、非法或悬空引用、无效坐标、无法容纳的元素及非法重复讲稿分配、引用失效或无法正确生成备注等确定性同步错误阻止依赖它们的导出。零页禁用导出。问题修复后自动更新，不能持久化第二套问题真值，也不把旧检查结果用于新版本。

能够确定性恢复资源或修复格式的问题由系统处理；涉及已有人工内容改写时展示候选及影响，再应用为一次可撤销修改。来源问题复用来源定位，讲述待安排复用原有分配入口；不为检查重新实现一套页面编辑器。标题、图像较小、叙事顺序、过渡与科学措辞属于提醒，普通建议不阻止导出、不要求点击忽略或逐项确认。未分配讲述保留提醒，不自动等同于用户省略发现；讲稿修改后的页面更新建议只提醒，不能以“尚未重生成 PPT”阻断下载。真正的非法引用、重复分配或备注生成错误仍阻断。

用户可以主动舍弃图或部分讲述，系统保留论文原图和证据关系，只对覆盖变化提醒，不要求重新添加或填写理由才能下载。某图未展示不等于发现被省略，发现仍可能由讲稿或其他证据表达；只有仍被当前稿件使用的必需图源不可用才按资源故障拦截。明确舍弃整项发现时，可由用户操作生成省略记录，不能把自动漏提取伪装成人工选择。

内容或图组超出页面、导出会裁断文字/图片等无法容纳的问题必须处理；不能归为“覆盖不足”放行，也不能通过静默删图、丢弃讲稿或把字号缩至不可读来清除。修复、调整分页或用户明确删减后重新校验，仍存在阻断项就不能下载；校验通过后不要求用户再逐项确认。

最终校验使用同一个导出用例：保存当前输入，捕获 Deck 与绑定 Paper 的版本、完整讲稿和裁图快照；启动前版本变化重新检查，启动后不混入新编辑。必需资源失败停止打包并提供恢复/重试，不下载缺图半成品。保留进度、取消、防重复点击、失败重试；原生文字可编辑、图像等比、讲稿进入对应讲者备注。旧稿允许保留并导出原版，不混合新旧来源。检查通过不宣称科学事实已验证。

#### 当前原型的实现边界

[幻灯片 HTML](../prototypes/slides.html) 已合并检查入口、页上提示、右栏问题筛选/定位、原有讲述分配和顶栏导出；不设独立检查步骤。检查从本页当前示例数据派生，编辑、删页、撤销和 AI 应用后更新。默认不制造阻断项；底部“演示阻断问题”可选择页面放不下或必需图源未就绪，演示下载拦截、修复与撤销。

目前仅演示图源状态、模拟页面溢出、空标题、图组数量和待安排讲述，未实现真实 PDF/几何/科研校验。点击导出自动核对当前示例，普通建议不要求确认，阻断时自动打开面板并定位，成功流程固定页与讲稿快照，取消后不再出现完成结果。没有生成 PPTX，也不调用真实模型。真实资源重试及人工内容修复仍遵守上述应用契约，不能把演示规则当作生产检查算法。

原 check-export.html 只作为旧书签兼容入口，跳转幻灯片检查面板；旧独立页面实现由 Git 历史保留，不再作为有效设计稿维护。
