# 幻灯片编辑、检查与导出

> v0.5 目标设计，应用尚未实施；图源、大纲与讲稿、幻灯片三页 HTML 已获用户确认。当前进入[检查与导出 HTML](../prototypes/check-export.html) 讨论；当前实施状态见 [执行目录](../execution/README.md)。

### 3.6 幻灯片编辑工作区

#### 分页与图组的职责

用户从大纲与讲稿点击下一步后，系统依据完整讲述及多对多 Panel 证据自动建议页面边界、图组和版式并制作草案；完成后停在幻灯片工作台。分页不提前放在大纲页，也不把一段讲稿固定成一页。

支持一段跨多页、多段合一页、同一 Panel 跨页复用。按完整句意分配讲述，页面始终可追溯到相应讲稿；分配与备注不重复整段、不漏句。用户能调整页边界、拆页、合页和重排，操作同时维护关联，一次 Undo 恢复。删页保留论文事实和讲稿内容，对未分配内容显示待安排，不把删页自动解释成省略论文发现。

多个 Panel 服务同一结论时先建议同页图组；内容过密则按讲述层次分多页，不以缩小到不可读换取一页。图组提供多选 Panel、自动排列、组内顺序/大小/间距调整，每个 Panel 仍是独立引用和可编辑图像，不烘焙成失去来源的拼接位图。复用已有 panel-grid/two-figures 和共享几何；图组选择、排序、列宽和间距控件已在 HTML 确认，持久化参数在实施阶段按架构契约细化，不扩展通用自由画布。

图组可跨 Figure 选 Panel，包括当前 PDF 中的附图；保留原图号与 Panel 标签，来源不随位置变化。附图身份独立于汇报主线/补充标签，可提前用于主线，同图可再次解释。用户不需要重找内容或维护来源数组。

本页修改讲稿、分配或图组后，更新相关页面和备注的候选；已有人工内容先预览再应用。点击检查只切换到检查视图，不隐式导出或重新生成。

#### 画布与直接编辑

```text
┌────────────────────────────────────────────────────────────────────┐
│ 项目名 · 已保存           [幻灯片]                   [导出 PPTX] │
├──────────────┬──────────────────────────────┬──────────────────────┤
│ 主线 / 补充  │ 当前 Slide Canvas            │ 内容 / 图源 / 版式   │
│ ▾ 章节 3 页  │ 16:9，适配剩余空间           │ AI 对话 / 提案       │
│   05 缩略图  │ 选中图：[来源][裁图][删除]   │ 本页目的 / 结论      │
│   06 已选中  ├──────────────────────────────┤ 发现 / 来源 / 版式   │
│ ＋新增 / 删除│ 当前页讲稿（调高 / 收起）    │                      │
├──────────────┴──────────────────────────────┴──────────────────────┤
│ 当前页与进度     [展开 AI 输入：范围 / 提问或修改 / 输入 / 发送] │
└────────────────────────────────────────────────────────────────────┘
```

| 区域 | 控件与行为 |
|---|---|
| 顶栏 | 沿用[工作台外壳](../ui/工作台与公共交互.md)两行外壳；当前主操作与导出可见，低频操作进更多菜单 |
| 章节导航 | 主线/补充标记、章节折叠、页数、缩略图、编号、选中态；单选/多选、拖动重排、新增与删除 |
| 中央画布 | 默认连续滚动，目录、底部讲稿与右栏跟随当前页；可切换专注当前页，返回连续列表。缩放仅改变查看比例；点击文字编辑，选中元素有操作，不提供整页任意元素的自由坐标手柄；图组内使用有限调整控件 |
| 讲稿面板 | 当前页讲述内容；与页面选择同步，可独立滚动、调高或收起，保存时维护对应关系 |
| 右侧 Inspector | 内容/图源/版式/AI 可切换、可收起；展示页目的、结论、来源、布局、图像操作或对话与提案 |
| 底部命令区 | 固定紧凑状态条与可展开 AI 输入；实际范围、模式和发送/取消始终在其区域内可达 |

AI 对话与输入共用一个 controller 和请求状态；右侧不再设第二输入框。切换标签、收起面板或浏览页面不扩大范围，也不发起新请求。无可用 Undo/Redo 时禁用按钮；持续显示当前页/总页数。

- 新增页使用文字布局，标题和空文字可编辑；占位提示不写入导出。保留换行、焦点、光标和输入法；编辑结束一次保存与撤销，不逐按键写历史。
- 删除页或元素可撤销，不逐次弹确认；允许多选删页和删空。系统维护章节、讲稿分配、来源与布局，不让用户为了删页修预算或补占位内容。叙事不足作为可定位提示，非法悬空引用不能写入。
- 零页显示“还没有幻灯片”和“新增页”，清除失效选择，保留 Undo/Redo，禁用导出。AI 不能把“这页”解析成不存在的目标。
- Figure 可查看来源、调整当前元素裁图或删除。单页裁图不修改论文底稿；修改论文切分明确进入图源工作区。
- 手工草稿使待提交的同范围 AI 修改失效并取消；单纯选择不取消。重复发送禁用。AI 的“撤销”只在对应修改仍在撤销栈顶时可用。
- 修改讲稿可请求更新相应页面，修改页面可请求调整讲稿；已有人工内容不被后台改写，差异应用是一笔可撤销操作。
- 整套重生成预填现有要求，复用相同分步流程准备候选，大纲/讲稿完成后等待用户进入幻灯片。成功并获准替换后切换版本；已有手工成果的替换先展示具体变化。候选存在期间 Current 可正常编辑，基准变化使候选过期，保留当前稿并提示重新生成候选。

辅助面板由用户主动收起，中央画布使用释放的空间；不按窗口宽度自动转换为抽屉或纵向布局。底部命令区保持紧凑，桌面工作台的画布与主操作持续可见。

#### 编辑器的直接操作与 AI 辅助

默认选中上次查看页，首次生成选第一页；左侧缩略图不在中间内容区重复。中央页工具栏显示当前页标题/编号、布局、Undo/Redo、适配与讲稿开关。页面上的文字点击进入编辑，Figure 点击显示“来源 / 本页裁图 / 更换 / 删除”；不让用户先在巨大属性表中查找对应元素。更换图源只能选论文已有 Figure/Panel，不新增通用图片库。

右侧默认显示所选对象的内容或图证据，未选元素时显示页面属性；“AI”是并列标签，不默认占据全部屏幕。布局以六种带名称的小预览选择，不能显示 layoutId/JSON。页面新增、删除和重排同时有可见按钮及键盘替代；多选仅在缩略图导航中发生，删除前显示选中页数，删除后可撤销。

讲稿默认显示当前页文本与“编辑 / 收起”，高度有限且可调；长讲稿在面板内滚动，需要专注编辑时跳到大纲与演讲稿的对应段落。来源、讲稿、页面共享定位，避免在多个视图反复找同一发现。

底部 AI 输入默认折叠为紧凑入口，展开后显示范围、提问/修改、输入、发送/取消；输入框多行高度有上限并内部滚动。右侧只展示对话、进度、候选差异和应用/放弃，不设第二输入。提案预览固定列出受影响页和讲稿，选择前后版本只改变预览，不改当前稿；手工修改导致提案失效时保留解释并提供重新请求入口。

#### 已确认的幻灯片 HTML

[幻灯片 HTML](../prototypes/slides.html) 使用七页固定示例，首开选第二页演示图组。一段讲稿跨两页、多段讲稿同页、Panel 跨页复用均可检查；连续滚动/专注模式、右栏调宽、讲稿调高/收起、文字编辑、讲述移页、按句换页、合页、删页后重新安排、图源多选/排序/列宽/间距及 Undo/Redo 可操作。

初始左栏 200px、右栏 320px、讲稿区域高 210px，均为讨论稿尺寸。长目录拖动支持边缘自动滚动，并提供上移/下移；只调整页序保留章节与主线/补充标签。显式换章节或跨章合页才迁移片段归属。合页保留前页标题、合并屏幕文字和讲稿、去重图源，不自动改写人工文字。

组图倍数控制列宽，网格同列共用；图像等比显示，不烘焙为单张位图。分页初始保留独立图组引用供分别调整。当前 HTML 的版式、大小控件、讲述分配及 AI 交互已获用户确认；确认设计可行不等于应用已实现。

四页 HTML 独立保存示例状态：大纲页下一步打开固定页面草案，不把前页编辑实际生成 PPT，本页讲稿也不回写另一份 Demo；真实应用仍使用同一版本化内容契约。检查入口打开检查与导出固定示例，未实现模型生成、真实导出、PDF 裁图或真实 AI 修订。

原型已补齐底部“展开 AI 输入”和右栏 AI 对话。输入支持当前页、所选页面、整稿范围，以及提问/修改模式；发送后范围固定，浏览其他页不会改变待应用目标。新回复定位到差异；用户可应用、放弃或取消，应用作为一次 Undo 保存，手工编辑使旧建议失效。收起输入不丢本轮对话，刷新仅恢复已应用的页面编辑，不恢复请求或待应用建议。

当前使用明确标注的固定规则模拟：可试“把图改为上下排列，缩小间距”“改成两列网格”或“精简屏幕文字”。提问仅返回只读范围摘要；无法演示的自由要求会明确提示未执行。真实应用通过 AI 对话修改讲稿、分页和内容的范围仍按上文契约，不能以此 Demo 证明模型能力。

### 3.10 检查与导出

```text
┌────────────────────────────────────────────────────────────────────┐
│ 项目名 · 已保存                                      [导出 PPTX] │
├──────────────────┬──────────────────────────┬──────────────────────┤
│ 阻止导出         │ 当前问题的页面或图证据   │ 问题原因与影响       │
│ 内容建议         │                          │ 定位 / 修复 / 重试   │
│ 覆盖情况         │ 选中对象与来源高亮       │ 原文或讲稿依据       │
│ 问题列表独立滚动 │                          │ 上一项 / 下一项      │
├──────────────────┴──────────────────────────┴──────────────────────┤
│ 当前检查范围与定位状态；科学解释不冒充已验证                       │
└────────────────────────────────────────────────────────────────────┘
```

检查使用相同外壳，左侧按“阻止导出 / 内容建议 / 覆盖情况”筛选，中央只展示当前问题的页面或图证据，右侧解释影响与恢复操作。每条问题有简短标题、位置、原因和明确动作；下一/上一问题保留过滤条件，解决后移除问题并保持邻近位置。无问题显示当前稿已完成的检查范围和导出入口，不能显示“科学事实已验证”。上图为内容区域示意，导出主操作统一放顶栏，不在底部再复制第二个高强调按钮。

检查视图与顶栏使用同一导出用例。资源缺失、非法或悬空引用、无效坐标、无法容纳的元素、未解决的内容同步冲突阻止导出，并给出定位和系统修复/重试入口。零页禁用导出。

叙事比例、标题、重复表达、较小图片、缺少过渡和科学措辞属于提醒，不再强迫用户补页或逐项确认警告。可查看已整理发现的主线/补充/用户省略情况；另在论文视图呈现提取/关联缺口，不能用“已覆盖全部已识别发现”宣称全文没有遗漏；不能把自动遗漏包装成人工取舍。讲稿与页面分别检查来源、分配与一致性，但不建设第二套模型评分器或要求用户逐句验真。

保持问题定位、导出进度、防重复点击和失败重试。检查绑定已保存 Deck 及其论文版本；导出前版本变化重新检查，导出开始后固定快照。原生文字可继续编辑，讲稿进入对应页的讲者备注，图片不拉伸。尚未更新的人工稿允许先保留原版并导出原版，不混入新旧两套来源。

#### 检查与导出 HTML 讨论稿

[检查与导出 HTML](../prototypes/check-export.html) 沿用已确认的桌面外壳和居中导航；当前是待确认稿。左栏 252px，右栏初始 344px 并可拖动，中栏按剩余空间展示定位对象；三栏独立滚动。顶部保留唯一导出操作，检查摘要显示阻断项与普通建议，不以科学评分代替检查结果。

- 左侧三类入口带数量，上一/下一项保留分类；修复后移除问题并选择邻近项，空分类显示检查范围与返回入口。
- 中栏在“页面”和“图与原文”间切换，显示当前对象高亮、对应讲稿、图注和原文句子；覆盖项展示发现的主线/补充/用户省略去向。省略原因保留，不把未知关联自动解释成用户取舍。
- 右栏说明问题原因、导出影响与修复入口。修复先展示具体前后变化，应用后重新检查，支持撤销；撤销或稿件改变后旧检查不能直接授权导出。
- 示例包含两个阻断项（资源未就绪、文字边界）、两条不拦截导出的内容建议，以及六项已识别发现的去向。另列一处原文关联待复核，不能用这些数量证明全文无遗漏。
- 底部 AI 入口沿用公共外壳，演示只读问题解释，修复回到同一详情预览。未接入模型，不执行自由修改要求；切换对象取消正在生成的示例回复。
- 导出展示固定稿件快照、阶段进度、取消和失败重试；底部“演示场景”可切换仅建议、无问题、过期检查、导出失败和零页。取消不继续弹出完成结果，普通建议无须逐项确认，零页与过期检查禁用导出。

本页状态独立保存，回到编辑页只打开另一份示例，不验证或修复上一页的实际数据。资源、修复和导出均为固定模拟，不生成 PPTX 文件；真实检查应从同一稿件快照计算，不能沿用 Demo 的场景状态作为应用结果。
