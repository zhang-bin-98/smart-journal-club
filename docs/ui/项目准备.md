# 项目管理与新建准备

> v0.5 目标设计，应用尚未实施。用户已确认项目准备归入新建流程，一份主论文 PDF 加一份可选补充 PDF；[项目管理 HTML](../prototypes/projects.html) 已获用户确认，包含存储概览。当前状态见 [执行目录](../execution/README.md)。

### 3.2 项目管理

项目管理是工作台的入口，不占据论文分析、图源核对、大纲与演讲稿、幻灯片四个步骤。页面以项目列表为中心，顶部显示新建项目和模型设置，搜索与阶段筛选位于列表上方；不以大幅上传区占据已有用户的主要空间。

| 区域 | 内容与行为 |
|---|---|
| 项目列表 | 名称、论文原标题、主论文/补充文件数量、四段式阶段进度条、最近修改时间；已有 Deck 时显示页数；按最近修改排序 |
| 存储概览 | 列表上方显示本站点在当前浏览器的估算已用/配额、比例与估算剩余；另列本应用论文文件统计；支持刷新，筛选不改变总量 |
| 查找 | 按项目名称或论文标题搜索，按当前阶段筛选；无匹配保留查询并允许修改，不显示新建成功假状态 |
| 项目操作 | 打开、重命名、删除；打开恢复已保存阶段与查看位置，不自动分析或续跑模型任务 |
| 空状态 | 无项目时提供新建第一个项目入口；与搜索无结果区分 |
| 删除 | 明确确认将删除项目、全部 PDF、工作底稿及编辑成果，模型设置不删除；保存/删除失败保留当前记录并提供重试 |

项目名称与论文原标题分开，用户重命名后不被后续自动标题覆盖。长名称可查看完整值，不挤掉操作。模型设置是全局入口，项目删除不删除配置。实际项目保存在当前浏览器，跨浏览器不自动同步。

项目当前阶段使用“分析 / 图源 / 讲稿 / 幻灯片”四段进度条：实心表示已推进的步骤，空心强调当前步骤，浅色表示尚未开始；待分析时四段均未开始。条上保留“分析中 / 分析就绪 / 待核对图源”等具体状态；分析就绪仍处于第一步，只有用户点击下一步才进入图源核对，不能将等待核对画成正在处理。此条表示工作流程位置，不表示解析耗时百分比，也不将进入幻灯片等同于已经完成或可导出。

### 浏览器存储概览

- 汇总当前浏览器中的全部项目，不随搜索/阶段筛选变化。应用论文文件统计按唯一资产的 Blob 大小相加，主论文和补充材料分别计入；不把复制底稿的同一资产重复计数。没有精确应用数据库/缓存分项时不编造数值。
- 浏览器 estimate 返回的是整个站点 origin 的估算已用和配额，可包括数据库、缓存及同源其他路径应用；不是系统磁盘空间、smartJC 独占容量或永久可用保证。PDF 文件大小与站点占用不可相加，以免重复统计。
- 有有效配额时显示比例/估算剩余；读取中、读取失败、接口不可用分别显示状态与重试，未知不写成零，异常数值不生成 NaN 或负数进度。接近配额时提示可删除不需要的项目，沿已有逐项目确认，不新增一键清空或自动删除。
- 首次进入、项目创建/删除成功后和用户点击刷新时更新；浏览器估算可能滞后，时间标识表示本次读取时间。估算提示不替代真正写入结果，保存失败继续保护草稿。
- HTML 默认展示明确标注的合成存储概览（固定示例配额与缓存、文件信息统计），可切换接近上限/不可用场景或只读查看浏览器估算。上传的 PDF 未真实保存，文件统计不是实际持久化字节；file URL 无法估算时直接说明，不偷偷改用示例当作实测。

模型设置入口进入独立[配置页](模型配置.md)；保存或返回恢复项目列表位置。新建过程中进入配置时，创建会话保留文件与输入，原型仅保留示例文件信息。

### 新建项目弹窗

```text
┌────────────────────────────────────────────────────────────┐
│ 新建项目                                                × │
│ 主论文 PDF（必填）             补充材料 PDF（可选）        │
│ [选择文件 / 拖放一份 PDF]      [选择文件 / 拖放一份 PDF]   │
│ 文件名、大小、移除             文件名、大小、移除          │
│ 项目名称 [自动填写，可修改]                                │
│ 汇报要求 [语言、听众、时长、重点等，可留空]                 │
│ 模型未配置时原位提示，并提供设置入口                       │
│                         [保存，稍后开始] [开始分析]        │
└────────────────────────────────────────────────────────────┘
```

- 主论文恰好一份，补充材料零或一份；各自支持选择和拖放、显示文件信息、创建前更换/移除。补充材料不是另一个项目，也不要求主论文和补充文件同名。
- 必需文件未选择或仍在读取时不能提交；非 PDF、不可读、保存失败等错误显示在对应位置并保留其他有效文件及输入。文件头校验不能代替实际解析验证；扫描、加密和损坏文件仍按产品支持边界处理。
- 项目名称先取主论文文件名，可修改；解析后仅在用户未自定义时以主论文标题补充，不以补充材料封面替换原标题。
- 汇报要求为自然语言可选输入，允许语言、听众、时长、重点和篇幅；留空按论文主要语言充分覆盖发现。要求影响大纲、讲稿和页面取舍，不改变两份材料的全文提取范围。
- “保存，稍后开始”原子保存项目、全部已选文件和要求，回到列表标记待分析；不需要模型配置。“开始分析”先执行相同保存用例，再发起分析任务；任务失败或取消保留已经创建的项目。
- 模型未配置时在弹窗提示并进入统一设置，返回后保留文件选择与要求；不要求用户为保存项目先配 Key。重复提交禁用，不创建重复项目。
- 关闭弹窗保留本次未提交输入供重新打开，只有显式提交才创建项目；未提交文件不承诺跨刷新恢复。实际保存失败不得显示成功或丢弃草稿。

创建完成后不另设“项目准备”页面；从列表打开待分析项目进入论文分析页，查看已保存文件与汇报要求并显式启动分析，可直接在论文分析页左栏修改汇报要求，公共设置入口复用同一项目偏好。第一版继续保持材料固定绑定，不支持在已创建项目中追加或替换 PDF；需要变更材料时新建项目，保护原稿。

### 主论文与补充材料的共同处理

两份 PDF 的正文、方法、表格、完整图注及 Figure/Panel 都参与解析和理解，合并到同一 Paper 的发现与证据体系。每处来源标明文件角色、文件名及文件内页码；同页码/图号不能混淆。图源目录按来源分组并可连续浏览；主图/附图可混合参与任意讲述。来源文件角色、论文图号、汇报主线/补充是三个不同概念。

全部已上传材料及人工补选页的必需处理完成后，用户点击下一步才进入一次整体图源核对。出错定位到对应文件与页，重试复用有效阶段，不让用户修来源 ID，也不把主文件完成冒充整篇完成。具体字段、事务和旧单 PDF 迁移见[数据模型](../architecture/数据模型.md)、[数据约束](../architecture/数据约束.md)和[工作流与存储](../architecture/工作流与存储.md)。

### 当前 HTML 边界

原型包含三个合成项目，以四段进度条显示阶段，可搜索/筛选、重命名、删除，支持双文件选择/拖放、基础文件头校验、未配置状态、保存稍后开始、模拟分析与取消。模型设置进入独立 Responses 配置原型，仅保存非秘密字段与示例 Key 标志，不接受真实 Key；新建示例只持久化文件信息和准备内容，不保存 PDF Blob、解析论文或调用模型。刷新不会恢复未提交文件或自动续跑分析。

打开已准备的项目先展示文件和阶段，工作台跳转打开独立固定示例，不载入该项目的真实文件。现有图源原型的双文件分组仍待接入，不能以本页上传演示声称完整链路已实现。

长时间解析在独立[论文分析页](论文分析.md)展示，项目列表显示阶段概要；启动后不再使用长时间进度弹窗。分析完成不自动切页，必须用户点击下一步。HTML 跳转仅携带示例项目身份与文件名，缩略图和处理内容为固定合成数据。独立 HTML 之间完整导航会停止模拟计时，返回后需点击继续；正式应用的视图切换不销毁运行任务。
