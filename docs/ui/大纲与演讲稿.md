### 3.5 大纲与演讲稿

```text
┌────────────────────────────────────────────────────────────────────┐
│ 项目名 · 自动保存                         [下一步：生成幻灯片]      │
│           论文与图源   [大纲与演讲稿]   幻灯片   检查              │
├───────────────────┬─────────────────────────┬──────────────────────┤
│ 章节目录          │ 讲述工具栏              │ 对应证据             │
│ ⠿ 背景与问题      │ 章节标题 / 主线或补充   │ 本段关联的多个 Panel │
│ ⠿ 发现一          │ 讲述目的与演讲稿……      │ 图注 / 原句 / 发现   │
│ ⠿ 发现二          │ 下一讲述段落……          │ 调整图源 / 查看来源  │
│ ⠿ 补充验证        │ 下一章节……              │ 查看该图用于哪些讲述 │
│ ⠿ 综合与局限      │ 跨章节连续滚动          │ 独立滚动 / 可调宽    │
├───────────────────┴─────────────────────────┴──────────────────────┤
│ 章节与讲述数量 · 发现覆盖                        [展开 AI 输入]     │
└────────────────────────────────────────────────────────────────────┘
```

论文发现覆盖、讲述逻辑及主线/补充去向主要在本步随编辑更新；用户省略保留原因，原文提取或关联缺口单独展示，不等到导出时要求用户逐项确认。幻灯片检查面板提供返回本页的入口。

本步决定讲什么、如何解释、证据如何支持叙事。大纲与演讲稿共同形成，先有完整讲述再进入下一步的[幻灯片分页与图组](幻灯片与检查.md)。本页不显示页数、页码、页面规划标签或拆页操作；段落拆分仅组织讲述，不创建页面。

默认充分覆盖已识别发现，标出主线与补充；不同发现不能为固定篇幅静默消失。用户可增删章节/段落、拖动调序、调整重点、拆分或合并讲述、修改正文和图源。用户可选择性删图或舍弃内容，覆盖变化只提醒，不强制补齐或填写省略理由后才允许下载；未展示某图不能直接判为遗漏发现。省略情况可查看，用户明确篇幅要求不改变论文底稿，不以重复内容凑数。来源登记和模型格式修复由系统完成。

#### 目录与连续编辑

左栏按实际讲述顺序列出章节，主线/补充为标签，不能分成强制固定先后的排序区。拖动章节连同其段落一起移动；改变标签不改变顺序，拖动不自动改标签。提供上移/下移作为键盘替代；段落也可调整顺序和所属章节。搜索仅筛目录，不删除中央正文。

中栏按章节顺序连续滚动，标题、讲述目的与正文可原位编辑。滚动同步左侧高亮和右侧上下文；点击目录定位对应章节。同步选择不重建正在输入的正文，跨章节编辑仍提交到原段落，输入法、换行、草稿与焦点保持。编辑结束自动保存，不逐段提交；一次操作一次 Undo。

拆分按完整句意保留正文，初始保留原图源供分别调整；合并保留两段正文并将图源去重取并集。删除讲述不删除论文事实、Panel 或其他讲述的关联。未覆盖发现可从覆盖入口定位，不能把自动遗漏标作用户省略。

#### 讲稿与 Panel 的多对多关系

一段讲稿可关联多个 Panel；一个 Panel 可被多段讲稿引用，包括跨章节复用。每条关联指向稳定来源身份，反向“用于哪些讲述”从现有引用查询，不复制 Panel 或单独保存反向列表。

右栏默认展示本段全部已选 Panel、各自图注、正文原句与发现；允许多选和取消某一关联。已被其他段落引用的 Panel 仍可选择，取消本段关联不影响其他段落。来源查看和反向讲述入口可跳转，返回保留上下文。去掉重复的“讲述 N / 跟随所选段落”提示行。

主论文与已上传补充 PDF 中的主图/附图都可参与任何讲述；论文图号、Panel 标签与来源保持原样，汇报顺序独立。附图进入主线不改变其论文身份，也不要求联网获取额外附件。

#### 分步推进、修改与恢复

图源确认后生成大纲与完整讲稿，到本步停止自动推进。主按钮为“下一步：生成幻灯片”；用户触发时先保存正文，失败则保留草稿并在原处重试。按钮授权下一步规划与页面草案生成，不要求新增大纲 confirmed 字段；ready 仍是程序校验状态。

没有运行任务时编辑不显示“生成已暂停”。用户主动启动的生成可暂停/取消，保留最近完整成果；刷新不自动调用模型。已有 Deck 的大纲/讲稿编辑读取当前稿，标明所编辑版本；上游变化计算受影响页，下一步按需生成更新候选，人工内容先看差异再应用。不可因本步不展示页面而丢弃原页面或悄悄覆盖人工内容。

问题面板可定位到讲述或来源；未保存输入先保存或取消。AI 按需展开，限定当前选中对象，修改先预览再应用；不暴露原始工具 JSON、来源字段或模型格式修复工作。

#### 原型范围

HTML 展示六章、八段示例讲稿、多选图源、Panel 反向讲述、连续滚动、章节拖动、拆分/合并、撤销与浏览器保存。来源和覆盖为示意数据，不代表真实科学分析；下一步打开[幻灯片固定示例](../prototypes/slides.html)，两份 Demo 独立保存，不实际生成 PPT。示例存储保留旧讲稿、排序与图源关联，移除本原型旧的段落内页面字段；真实应用不得据此删除已有稿。
