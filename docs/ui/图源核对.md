# 论文底稿与图源核对

> 本页 HTML 交互已获用户确认；应用尚未实施，原型不代表真实切分准确率或生成质量。

进入本页前，论文分析及全部人工补选页处理须就绪，由用户在[论文分析页](论文分析.md)点击下一步；不自动跳转。返回分析页补选只处理新增或受影响内容，保留其他人工图框；必要来源变化使整体确认失效，旧稿绑定仍受保护。

### 3.4 论文底稿与图源核对

论文底稿涵盖全文结构、背景、问题、方法、实验观察、研究发现、作者解释与局限。每个可追溯事实关联原句或段落及页码；Figure/Panel、原文、实验与发现形成多对多关系。论文底稿不包含页面预算或 PPT 布局，不因用户少讲、不讲或删页而删除事实。分析无法确定的关系标明缺口，不补造原句、实验或 Panel。

```text
┌────────────────────────────────────────────────────────────────────┐
│ 项目名 · 已保存                           [确认切分并生成讲稿]    │
├──────────────┬────────────────────────────────┬────────────────────┤
│ 按发现 / 按图│ Figure 连续列表 / 原页定位       │ 当前 Panel 预览    │
│ Figure 1     │                                │ 标签 B             │
│   A  B  C    │ 自动框 / 当前选中框            │ 对应图注与公共说明     │
│ Figure 2     │ 放大、平移、拖动框、调整四边    │ 正文证据（折叠）  │
│   A  B       │                                │ 切分疑点           │
│ 待核对 2 项  │                                │ 添加 / 删除 Panel  │
├──────────────┴────────────────────────────────┴────────────────────┤
│ 当前 Figure 与核对状态                 [展开 AI 输入]             │
└────────────────────────────────────────────────────────────────────┘
```

各视图线框展示内容布局，顶部导航与主操作均复用[工作台外壳](../ui/工作台与公共交互.md)外壳，不在底部重复放置生成按钮。核对的主要对象是切分。左侧完整列出 Figure 与所有 Panel，支持按发现切换组织；点击图、框或预览同步选中，定位原页和对应原句。左侧目录与中央 Figure 列表分别滚动；中央连续排列完整 Figure 及切分框，滚动即可检查下一张，导航同步高亮当前位置，也可直接跳转。工具栏、侧栏和主操作始终可见。发现和解释可查看、定位、提出修订，但不要求用户逐项审核或填写领域字段。

手动操作包括移动/缩放整图与 Panel 框、添加漏掉的 Panel、删除误框、修改标签、Undo/Redo、恢复自动结果。原页与实际裁图实时联动，保留放大查看能力；不要求输入坐标。修某一框不能偷偷移动其他框。保存通过统一图源提交入口，更新论文来源；“恢复自动结果”先进入草稿，可取消或撤销。新增 Panel 的语义与证据关联由系统补充，无法确认时标疑点，不要求用户填写 Source/Claim ID。删除仅移除该图源身份及其关联，不删除原文事实；相关关联由系统修复或明确标缺失。

自动切分采用“整图定位 → 局部高清识别标签、内容与粗框 → 像素内容/空白间隙辅助边界调整 → 质量检查”。保留完整 Figure；不按标签中点硬切、不按阅读顺序猜标签、不把固定阈值当所有论文的标准。不确定结果进入核对，不宣称语义与像素算法已经证明切分正确。

Panel 是可独立理解的科学裁图，保留数据、标签及必要坐标、组别、图例、比例尺和统计信息。共享图例或标注可以让多个 Panel 适度重叠；重叠本身不是错误，疑似串入邻图主要数据才提示核对。不抹白、擦除、重绘科研像素来制造分隔。矩形难以独立保留必要标注时保留整图并提示，可手动调整或在生成中组合展示，不强行产出残缺子图。

允许对当前 Figure 再次自动识别，结果先作为候选，与人工框对照；只有用户选择应用才替换。必须保留并标识人工调整，不得因重试或换模型静默覆盖。

一次整体确认绑定当前保存的切分版本，不等同于确认论文所有科学解释正确。切分改变后确认失效，影响范围可见；关联重算不要求重复核对未改变的框。确认后系统完成必要关联整理并生成大纲与演讲稿，完成后停在讲稿步骤，由用户决定何时进入幻灯片。

已有 PPT 时修改论文图源，先保存独立工作底稿并显示受影响的讲稿/页面，旧稿及上一版仍可查看、导出。应用下游更新才切换相关成果，不让共享源变化静默改变旧稿。完整重新分析同一论文沿用“在新项目中重新分析”入口；复制本地全部论文 PDF，保留原项目，失败不覆盖旧事实或成果。

#### 核对模式与选中行为

默认以 Figure 列表进入核对，左侧可筛选“全部 / 有切分疑点 / 人工调整”，也可切到发现或原文目录；筛选不是审核勾选，不改变整体确认语义。列表同时显示整图缩略图、Panel 标签和疑点数量，空筛选有“显示全部”。当前 Figure 未检测到 Panel 时保留整图与“添加子图 / 重新识别”，明确可直接使用整图；切分疑点仍可见，不能将空列表冒充已确认科学结果。

中央以适应宽度的 Figure 连续列表进入，工具栏提供“选取 / 添加子图 / 调整整图”、放大缩小、适配和原页定位；滚轮默认滚动图列表，缩放使用明确控件或组合键，不要求每张点击上一/下一。拖框时保持当前图与滚动位置稳定，不在列表边缘自动跳图。普通选取只编辑选中框，八个手柄调整边界；画布获得焦点且无文字输入时，方向键微调选中框位置，边界手柄也可通过键盘调整，连续一次操作合并为一次 Undo；原图始终可见，遮罩仅用于 UI 弱化非选区，不改变裁图像素。共享区域重叠时点击左侧标签或右侧 Panel 列表可准确选中，不靠重复点击猜框层级。

工具栏独立提供“＋ 添加 Figure”，与“＋ 添加 Panel”“整图边界”并列。添加 Figure 打开原页框选，选择已上传文件及文件内页码，拖出整图范围。原图号使用可搜索、可输入的选择框：选择已有 Figure 时默认将选区作为该图的跨页接续图块，输入新图号则创建 Figure 与首个图块；留空仍可创建未标号新图。下拉项显示来源文件/页码以区分同名图，选择绑定稳定 Figure 身份；输入恰好匹配唯一已有图号时显示追加归属，同名有歧义须从列表选择，不能猜测或合并两个既有 Figure。弹窗显示本次创建/追加的归属，切换图号保留已画选区。取消独立“添加跨页图块”按钮与更多菜单入口，统一复用现有八手柄、裁切预览、取消和一次 Undo；“整图边界”始终只调整当前已有图块。

点击中栏图卡标题的 Figure 名称进入原位编辑，复用新增弹窗的可写可选图号控件。编辑对象是当前单页图块：选择其他已有 Figure 或输入唯一匹配图号，保存时必须弹确认框，列明原归属、来源页、目标 Figure 与仅移动当前图块的影响；确认后成为目标 Figure 的分块。输入不存在的新图号则将当前图块独立为新 Figure，原 Figure 的其他图块不变；原值未改或仍选当前 Figure 不产生修改、不弹确认。重名有歧义先从列表选择；允许未标号新图。Enter/保存提交，Esc/取消放弃；有展开列表时 Esc 先收起列表。取消归入确认回到原位草稿，不丢输入。图块、Panel、边框及原文来源保持，目录与标题同步，整个操作一次 Undo；不把用户改号当成改写原论文图注。编辑期间保存或取消后再进行其他修改，未保存输入不得被刷新列表覆盖。

图源目录保留人工补选但成功处理后仍未定位整图的原页入口；一页漏一张图可直接补框，保留其他结果。原页、图号与关联由系统维护；新增后自动补做 Panel/图注关联，失败保留人工框并给局部重试。自动补充不覆盖人工调整；无必要细分的单图允许直接保留整图，不以 panels 为空阻止整体确认。真实分析请求失败仍按失败处理。

同一 Figure 的多个单页图块连续展示并注明文件与页码，Panel 归属具体图块；图注可独立跨页。原图号与图块序号区分，跨页时不重复编号成另一张 Figure，后续可引用图块或 Panel 组成 PPT 图组。

“添加子图”进入明确框选模式，拖出有效框后在原处填写标签，Enter 结束，Esc 放弃；未知标签允许暂不填写，不按位置猜 A/B/C。Delete 仅在画布选中框且无文字输入焦点时删 Panel；整图身份不套用该快捷键。拖框中右侧显示实际裁图预览，松手后一次保存；无效框就地说明，不跳到错误页面或要求输入坐标。

右侧按顺序显示当前 Panel 裁切预览、标签与 Panel 选择、默认展开的对应图注及中文释义、适用的公共说明。“展开完整图注”显示原文上下文并高亮关联片段；“正文证据与发现”默认折叠，切换 Panel 后更新当前关联内容。科学信息使用自然语言，Source/Claim ID 不进入用户表单。点击原文可在原页定位并返回。

预览必须严格裁切到中栏的选区，等比显示。右侧栏宽度或选区长宽比变化只影响显示尺寸与留白，不能显示选区外的相邻子图。矩形裁切不等于擦除或重绘科学像素。

“重新识别当前图 / 恢复自动结果”放在图工具栏更多菜单。候选通过自动框与当前框叠加切换、对应裁图前后对照展示，固定显示应用范围；应用或放弃不需离开 Figure。疑点可逐条跳到框，不能用“全部已查看”代替用户实际切分确认。

#### 只读 AI 问答

AI 仅解释图注、查询原文和定位证据；默认当前 Figure/Panel，发送时固定来源对象，滚动到其他图后回复仍标明原目标。没有“修改”模式，不通过自然语言改边框、添加/删除、改图号/归属、标签或图注关联，也不从聊天触发重新识别。用户提出修改要求时指向已有控件，不假装已经执行。

手工工具及“重新识别当前 Figure”保留，后者由按钮触发并先展示候选，应用后一次 Undo；只读问答与重新识别不共用写权限。统一能力边界见[页面 AI 契约](../architecture/编辑与Agent.md)。当前 HTML 未实现 AI 问答，维持已确认的图源编辑原型，不能将本节当作实测能力。

#### 浏览状态与整体确认

目录区分未查看、已查看、已修改及切分疑点。“已查看”由浏览位置记录，只是导航状态，不是审核通过或生成授权；不要求逐 Figure/Panel 打勾。用户完成所需检查后统一点击“确认切分并生成讲稿”，先保存当前切分，再启动后续自动流程。浏览计数与科学确认分开，关联疑点不新增逐条确认门槛。

#### Panel 与图注、正文的对应层次

| 层次 | 可追溯内容 | 展示方式 |
|---|---|---|
| Figure | 完整 figure legend，包含原页位置与公共说明 | 整图模式看完整图注，Panel 模式可展开全文 |
| Panel | 图注中的句子或片段，以及适用的公共说明 | 默认展开，完整图注高亮相关原文，译文明确为解释 |
| 证据与发现 | 正文的原句/段落位置，实验观察与所属发现 | 默认折叠，可定位原页；允许一句或发现关联多个 Panel |

图注与 Panel 多对多：例如“b–c”同一片段关联 b、c；统计方法、样本量、误差线说明仅分配给实际适用的 Panel，不把整图所有公共说明无差别复制给每个子图。原文不因标签变更而改写，不能从图注描述自动推定正文结果或因果结论。

“调整关联”提供图注原文片段的多选与公共说明选择，允许应用、取消和一次 Undo。自动关系不确定或补删/改标签后标“关联待确认”；拖动几何边界保留 Panel 身份及原关联，标签修改保留旧关系并提示复核，不能静默覆盖手动关联。未知新 Panel 由系统尝试补充，不能要求用户自行找到所有内容或填 ID。

#### 已确认 HTML 与实施边界

[图源核对 HTML 原型](../prototypes/figure-review.html) 已经用户确认页面可行，是本页的交互讨论稿。直接在桌面浏览器打开即可，无外部依赖；公共导航与“确认切分并生成讲稿”入口随新流程同步；示例图、图注、正文和生成进度均为模拟，浏览器保存仅是 Demo 状态。实际 PDF、模型分析、分步 PPT 生成、资源调度、冻结 Paper 和应用事务仍按实施阶段交付。

原型已覆盖连续浏览、修框/补删/改标签、图注关联、拖动侧栏、局部保存及撤销；本轮补充独立添加 Figure、在合成原页框选与调整后应用、原图号选择/输入决定追加图块或创建新图、标题原位改号与归入确认、无 Panel 整图确认。新增原页是固定合成素材，不读取 PDF、不执行自动切分或真实图注补充。原型初始 4 张 Figure SVG 与新增框选用的固定合成原页、部分按钮禁用、自动分配示例标签、Demo 撤销上限及模拟阶段次序不作为应用契约；未演示的候选重识别、原 PDF 定位等仍以本规格及架构为准。本轮双 PDF 的分组与来源标识已纳入规格，现有 Figure HTML 只演示来源角色与页码，未实现按文件分组的完整目录，未据此宣称双文件定位已完成。

### 主论文与补充文件

两份 PDF 共用同一图源核对工作台和一次整体确认。目录按主论文/补充材料分组，Figure 仍可跨分组连续滚动，不要求逐张点击；图卡和原文位置显示文件角色、文件名、文件内页码和原图号。Panel 图注关联按来源文档定位，完整图注或证据跨文件时保留各自来源。主/附图身份不改变后续汇报主线/补充安排。
