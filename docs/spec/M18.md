## 完成内容

- `src/app/workflows/planSlides.ts` 在用户进入下一步后规划页面，按段落边界分批、无损细分长片段，完整分配所有讲稿；有限修复后保存 `deck-plan-ready`。`generatePresentation.ts` 随后自动调用纯 Build，恢复已保存 ready 计划不再次请求模型。暂停、取消、编辑和基准变化拒绝迟到提交。
- `src/modules/presentation/content/page.ts` 维护共同的页面元素、图像实例与分区定义；`planning/`、`editing/`、`layout/`、`build/` 分别承担规划、Deck 修改、几何和纯构建合同。Plan/Deck 不相互导入内部实现，布局不依赖其生命周期；旧路径保留兼容重导出，清理留在 M19。
- 图组采用最多四图、深度不超过三层的有限矩形分区；横排、竖排、网格、左二右一、上二下一及有限比例候选，保持原图顺序。保存比例、间距、实例 ID 和页内 cropOverride，输出分区框与等比 contain 实际图像框。新旧预览与导出共用 `layout/computeLayout.ts`；旧稿没有图组时继续使用原六布局几何。
- `src/ui/presentation/SlidesPage.tsx` 及其控制器、Canvas、Inspector、来源和版本组件提供固定桌面工作台：两行导航、可折叠章节与可见范围缩略图、连续/专注视图、直接编辑、可调分栏/讲稿高度、页序拖动与键盘操作、分页/跨章合页、多选删除、唯一讲稿分配、原图定位与仅本页裁框。图组候选先看实际前后预览；分隔线拖动/方向键及比例/间距输入，结束后一次保存和 Undo。重新打开恢复最近浏览页。
- `DeckSession` 增加输入登记与版本捕获，继续复用唯一提交和 Undo/Redo；保存成功才推进状态，保留未变页面对象，避免局部文字修改重建全部缩略图。讲稿区按 speechIds 顺序显示，备注直接从同一正文派生；删页留下未分配讲稿，跨章合页不迁移段落章节。
- `src/app/assistant/slidesAssistant.ts` 复用 Pi Agent 及统一请求调度。只读问答没有修改工具；修改先生成内存预览，发送时绑定页面、讲稿及插入位置范围，应用前重查版本/草稿，经同一个 DeckSession 提交并一次撤销。
- `src/infrastructure/persistence/slidesStore.ts` 同事务保存首次 Current 或完整候选与项目引用，保留其冻结 Paper。再次失败保留旧候选；重开不重建，过期只读，应用前重查 Current/Previous/Paper/核对/偏好基准；切换成功才更新实际生成偏好。恢复上一版检查双方版本，有界回收不再引用的稿件/底稿，发现跨项目引用时拒绝回收。
- 大纲默认编辑 Current；明确准备或打开新稿讲稿时编辑工作 Plan，生成后切换到实际新计划。修改计划清除旧页面规划并回到 outline-ready，完整候选仍独立保留。
- `exportPresentation.ts` 统一复核已保存稿，硬引用/分配、资源缺失、空稿和新稿文字溢出阻断导出，普通内容/页面更新/未分配提醒不额外确认。`infrastructure/pptx/` 有界、按文件准备原图，取消释放 PDF，打包后再次检查取消，只有一个下载入口；输出原生文字、独立图片和对应备注。
- `prompts/stages/slides.md` 纳入现有提示词配置与构建检查。未新增应用依赖，未更换模型、PWA 或 Pages 发布配置。Vite 忽略本地验收输出目录，避免 Windows 占用中的 PPTX 触发监听 EBUSY；这是开发监听修复。

## 图组对照及限制

对照 [Justified Layout 官方说明](https://flickr.github.io/justified-layout/)及 [4.1.0 源码](https://github.com/flickr/justified-layout)，仅将对照包安装到被忽略的 `output/playwright/layout-reference/`，没有加入应用依赖。用同一论文 Fig 3/5/6 前 3/4 个 Panel 的真实宽高比，在相同逻辑图区、顺序与间距下比较；Justified 超出页高时整体等比缩放，保留完整图组。

`npm run check:m18:layout` 实测最小图像短边（逻辑点）：

| 图组 | 有限分区 | Justified |
|---|---:|---:|
| Fig 3 A/B/C | 185.0 | 193.9 |
| Fig 3 A/B/C/D | 147.9 | 149.3 |
| Fig 5 A/B/C | 163.3 | 97.3 |
| Fig 5 A/B/C/D | 122.5 | 107.4 |
| Fig 6 A/B/C | 162.9 | 193.1 |
| Fig 6 A/B/C/D | 147.9 | 149.3 |

- 有限分区对 Fig 5 的异形组合更有利，但六组中四组的最小短边不及对照；原始几何及并排图保存在 `m18-layout-comparison.json/.png` 与逐组 JPG。没有声称全面优于 Justified，亦未因候选库被列入文档而安装 React Grid Layout。
- 面积评分只解决有界排列；不能证明小字、图例或源框正确。并排图同样显示既有框带入邻图、切断部分标签等风险，布局算法没有修复这些科学图源问题。
- 自动初稿为完整发现稿，页数多且若干文字页稀疏；本阶段不擅自删减发现或固定预算。人工核查与必要修订仍需要，尤其源框问题会在复用同一 Panel 的其他页面出现；两页修订不等于整篇图源已全部人工修正。
- 真实质量验收限定于既有代表组学论文，未扩展到三篇全流程或更多模型/浏览器。三篇新主链整体科学内容复核、旧路径清理与实际发布复核属于 M19，本阶段未宣称完成。
