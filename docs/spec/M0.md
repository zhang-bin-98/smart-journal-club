## 已完成

- 建立 `BBox`、六类布局、Figure 引用和基础 Deck 校验；Web 预览与 PptxGenJS 导出共用 `computeLayout` 的归一化框。
- 接入 PDF.js 6.3.289 的页文本、首页渲染和随构建分发的 worker；按同一 Source bbox 生成裁图。
- 接入 IndexedDB `assets` store，保存和重读原 PDF Blob。
- 接入 PptxGenJS 4.0.1 导出；文字为文本对象，Figure 为等比图片。
- 增加 `.env` 忽略规则。已有本地 Key 未读取、未写入仓库或构建产物。
