## 完成内容

### 编辑工作区

- 编辑器改为三栏工作区：左侧章节导航按章折叠并显示页数、问题数、缩略图、页码和选中态；中间继续复用 16:9 Canvas；右侧新增 Content、Source、Layout、AI 四个 Inspector 标签。
- Content Inspector 接入本页目的和本页结论编辑，并集中展示页面类型、Claim、来源及选中元素；编辑继续经过 DeckSession、现有草稿队列和 repository，不新增持久化入口。
- Source Inspector 复用来源查看、当前元素裁图和删除；Layout Inspector 只使用既有六类布局。历史失效引用不会使 Inspector 崩溃，而由检查流程报告。
- 页面可在章内或跨章拖动；目标章节显式交给既有 move mutation，由领域层维护章节连续和空章清理规则。
- 宽屏 Inspector 可收起为窄栏，Canvas 随之扩展；窄屏章节导航与 Inspector 使用抽屉，底部命令区保持独立。

### AI 对话与命令区

- AI 对话、工具进度、流式回答、proposal 影响页、差异及应用/放弃保留在右侧 AI 标签。
- 整个编辑器底部新增独立命令区，承载选中元素、当前页、当前章节、整套 PPT 四种 scope、提问/修改模式、解析后的实际范围、输入及发送/取消。
- 右侧与底部共用同一个 assistant controller；没有复制请求状态、提案或 Agent loop。M10 的权限、取消、版本和一次 Undo 规则保持不变。

### 检查、定位与导出

- 新增统一的确定性 `checkPresentation()`：汇总 Deck 结构、叙事和证据规则，共享布局计算得到的标题过长、文字溢出/拥挤和小图警告，以及 PDF/图源资源状态。
- 科学正确性不由机器冒充判定；检查页固定提醒复核因果措辞，物种、组织、细胞、队列和组别，以及终点、证据强度、图例和统计信息。
- 错误和警告保留章节、页面、元素、Claim、Figure 等定位信息；检查页可返回真实页面并自动打开 Content、Source 或 Layout Inspector。左侧章节和页面同步显示问题数。
- 顶栏和检查页共用同一检查函数及项目导出用例。叙事、结构、引用、含图文稿缺 PDF 或零页等硬错误不能绕过；纯文字文稿缺 PDF 作为需确认警告。
- 警告确认键绑定已保存 Deck 的 ID/revision；保存新修改后确认失效。导出前重读项目并复核 Current Deck ID/revision，导出期间固定开始时快照。
- 独立导出状态同时禁用步骤切换和重复导出，顶栏显示进度；失败原因持续显示且当前 Deck 保留，恢复条件后可直接重试。
