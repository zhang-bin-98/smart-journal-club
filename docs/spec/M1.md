# M1 最小 Deck 与导出

- 日期：2026-09-06
- 状态：已完成；固定 Deck 编辑、撤销/重做和 PPTX 导出通过本地构建与浏览器页面检查，已补齐 Tailwind 样式统一与相关验证
- 工作分支：milestone/m1
- 目标：实现最小 Deck、六类布局、四类元素、手工编辑、页面管理、会话 Undo/Redo 与可编辑 PPTX 导出。

## 已完成

- src/types.ts 建立 Zod 约束的 Deck、Slide、四类 SlideElement、Paper、来源和 Figure/Panel 类型。
- src/layout.ts 统一六类归一化布局，校验布局容量、ID、Figure/Panel 归属、来源引用和 Deck/Paper 关系。
- src/deck.ts 实现受控 mutation、批量原子校验、删除元素后的布局回退、最多 20 条 Undo/Redo 快照，以及 revision 递增。
- src/main.ts 接入页切换、新增/删除、拖动重排、布局选择、文字编辑、元素新增/删除和 Undo/Redo。
- src/export.ts 使用同一 computeLayout 导出四类元素；空 Deck 禁止导出，Figure 按比例 contain，文字和引用保持文本对象。
- src/main.ts 使用 Tailwind 工具类实现桌面编辑器、缩略图、16:9 预览、选中/聚焦/禁用态与空 Deck 状态；src/style.css 只保留 Tailwind 导入、统一主题和 body 基础颜色。按钮和表单复用完整的工具类字符串，事件定位使用 data 属性，不依赖样式类名。
- 样式复查确认原 M1 提交重新引入了组件 CSS，现已迁回 Tailwind。规范写入架构文档第 1 节，产品文档约定统一视觉风格，AGENTS.md 引用样式契约并记录用户已授权 agent 推送远端。
- 桌面沿用三栏布局，窄屏改用纵向排列与工具栏换行，消除原有最小宽度造成的横向溢出；这是本次样式适配，产品文档中的抽屉交互尚未实现。幻灯片字号随预览容器缩放，运行时位置与尺寸继续由 computeLayout 生成。
- 右侧摘要显示实际 Deck 名称、页数和语言；颜色及控件状态统一复用主题。
- 修复样式检查暴露的空文稿状态更新顺序：删除最后一页时仍更新 Undo/Redo、导出和删除按钮状态。
- 修复导出检查暴露的原有 Figure 占位图编码问题：使用 PptxGenJS 支持的 base64 数据 URL，防止下载成功却遗漏图片；共享几何和导出接口未改变。
