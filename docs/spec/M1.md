# M1 最小 Deck 与导出

- 日期：2026-09-06
- 状态：已完成；固定 Deck 编辑、撤销/重做和 PPTX 导出通过本地构建与浏览器页面检查
- 工作分支：milestone/m1
- 目标：实现最小 Deck、六类布局、四类元素、手工编辑、页面管理、会话 Undo/Redo 与可编辑 PPTX 导出。

## 已完成

- src/types.ts 建立 Zod 约束的 Deck、Slide、四类 SlideElement、Paper、来源和 Figure/Panel 类型。
- src/layout.ts 统一六类归一化布局，校验布局容量、ID、Figure/Panel 归属、来源引用和 Deck/Paper 关系。
- src/deck.ts 实现受控 mutation、批量原子校验、删除元素后的布局回退、最多 20 条 Undo/Redo 快照，以及 revision 递增。
- src/main.ts 接入页切换、新增/删除、拖动重排、布局选择、文字编辑、元素新增/删除和 Undo/Redo。
- src/export.ts 使用同一 computeLayout 导出四类元素；空 Deck 禁止导出，Figure 按比例 contain，文字和引用保持文本对象。
- src/style.css 增加桌面编辑器工作区、缩略图、16:9 预览、选中态和空 Deck 状态样式。
