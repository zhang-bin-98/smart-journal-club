## 实际实现

- `src/modules/project/model.ts`、`src/modules/paper/` 落实 v2 项目与论文聚合：文件身份、全文块及原文偏移、多图块 Figure/Panel、发现与证据、页选择、分析单元及输入基准。document/figures/evidence 不反向依赖聚合入口；汇报要求不删减论文底稿。
- `src/infrastructure/persistence/projectStore.ts`、`paperStore.ts` 同事务保存双 PDF/项目、完整分析单元与输入基准，校验跨项目引用、人工覆盖及迟到提交。旧单文件按主文档迁移，保留图框和稳定 ID；工作 Paper 与 Current/Previous 各自绑定并按需要复制。旧稿和遗留 Plan 按自身 Paper 读取，缺失关系不编造，过期计划不阻断旧稿打开。迁移后的工作底稿重定位图源时，同步失效悬空的派生引用并由续跑补齐，冻结旧稿不改；页面选择版本未处理完不能就绪。
- `src/app/workflows/preparePaper.ts`、`src/app/paper/` 用注入的资源、存储与 M14 请求入口编排全文提取、图源发现/识别、逐页证据和全材料汇总。完整单元及时保存，取消和刷新不假完成，手动续跑只处理输入已变化或未保存部分。闲置会话最多保留 8 份全文/Blob 快照，运行及订阅会话受保护，释放后保留列表所需轻量状态。并行失败绑定真实文件/页，单元输出最多修复一次。
- `src/infrastructure/pdf/` 使用实际 PDF.js Worker 和有界正文 Worker 池；本地计算与模型请求分离。文本保留 PDF.js 可提取字符；图像任务、位图与缩略图有界，取消、崩溃和释放可恢复。原 `shared/pdf` 入口仅作旧调用兼容。
- `src/ui/HomePage.tsx`、`src/ui/projects/` 提供搜索/步骤筛选、重命名/删除、资产统计与浏览器存储估算，以及一主一补 PDF 新建。设置往返保留实际 File 和草稿，事务失败可重试，不产生半项目。
- `src/ui/paper/`、`src/ui/project/ProjectWorkspace.tsx` 提供固定窗口、双文件进度、全部原页的按需缩略图、补选/排除、汇报要求自动保存、可调分栏与只读问答。分析完成留在当前页；图源预览须手动进入。M16 的图源手工编辑和 M17/M18 的新讲稿/幻灯片生成未提前交付；旧稿编辑与导出保留，v2 项目不能误入旧单文件生成流程。
- 只读论文助手复用 Pi Agent 和 M14 共享调度，冻结请求的文件/页及底稿快照，没有写工具。初始仅传概览，通过只读发现搜索/分页与原页工具按需读取完整内容，避免整篇底稿挤占请求预算。composition 仅装配具体适配器。

## Gate 与限制

M15 的项目创建、持久化/迁移、Worker、正式分析工作台、可恢复完整单元、只读问答、旧稿保护及必要真实论文内容验收通过。静态检查、247 项单元测试、生产构建、固定浏览器、存储、设置、旧稿与 PWA 检查通过；本地链接、UTF-8、Markdown、差异与凭据扫描通过。按仓库约定提交并合并本阶段，M16–M19 未实施。

科学内容复核是必要人工抽查，不是零误差证明。原 PDF 少量字符为替换符，部分来源跨度跨较长图注；正文/图注的时间、单位和位点差异保留为原文冲突。最终摘要仍有措辞精度限制：个别“依赖雷帕霉素”表述须结合相邻句中明确的药物抑制方向；“融合期下降的蛋白”所指实际为蛋白上的磷酸化位点；“磷酸化组数据用作标准化”省略了饥饿对照范围。完整底稿分别保留饥饿信号扣除与总蛋白 TMT 比值校正，未将这些歧义当作新的机制或方法结论。高强度下本样例的最终汇总未通过，最终质量与完成证据仅对应用户确认的 low 汇总，不宣称所有强度均可完成。

默认沙箱辅助进程启动失败，命令通过已审批的本机执行通道完成。部分截图工具受同一问题阻塞；已通过本机读取查看项目、待分析、固定完成态和真实完成态截图，固定窗口、分栏、页卡状态及可读性通过。临时截图、模型结果、仅含状态/用量的响应诊断与测试浏览器数据均留在忽略的临时目录，未纳入提交。
