# 应用接口与适配器契约

> v0.5 目标接口设计，尚未作为应用 API 实现。名称沿用既有工作流职责；实现时按实际调用落地，不预建空接口。字段定义见 [数据模型](数据模型.md)，合法性见 [数据约束](数据约束.md)。

## 1. 调用边界

这里的接口是浏览器内模块间的调用契约，不是新增 HTTP 后端。UI 与 Agent tool 调用应用公开查询/命令；应用协调领域规则与事务；外部能力由 infrastructure 实现，通过 composition 装配。业务规则不能落进 UI、tool 或 repository。

| 调用方 → 提供方 | 允许传递 | 返回或通知 | 边界 |
|---|---|---|---|
| UI/tool → app 查询 | 项目、明确目标、读取的成果版本、查询范围 | 只读视图数据、可用操作及原因 | 查询不触发分析、写库或修复 |
| UI/tool → app 命令 | requestId、projectId、目标 ID/baseRevision、有限命令参数 | 提交后的版本与影响对象，或统一错误 | 同一入口校验范围，不暴露任意 JSON Patch |
| app → domain | 普通数据、明确变更、基准 | 新内容候选、引用/几何问题、影响 ID 集合 | 纯规则不读取 React/DOM/数据库或调用模型 |
| app → infrastructure | 明确资源/数据、有效任务与 AbortSignal | 完整结果、有限进度或统一错误 | 适配器不决定确认、下一阶段或人工覆盖 |
| composition → 各实现 | 已选具体实例与依赖 | 接线后的应用入口 | 只装配，不承载流程分支 |

## 2. 请求、返回和失败的共同规则

- 内容写请求包含稳定 requestId、projectId、目标身份与预期 revision。工作流另捕获 PlanRecord 基准、Paper 身份/版本、核对版本和偏好；具体结构复用数据模型，不在本文件复制。人工提交不伪装成模型任务，是否允许提交由应用协调。
- 一次成功提交返回已保存的内容版本及实际影响对象；UI 依据保存结果更新状态。只完成内存预览、模型返回或候选模拟不得报告已保存。宽度、缩放、选择等界面偏好不增加科学内容 revision，也不占用内容 Undo。
- 重复 requestId、基准过期、跨项目引用、失效任务和未保存冲突均拒绝提交，不强制覆盖；失败不推进 Current、revision、Undo 或历史。重复请求的拒绝语义沿 [编辑与 Agent](编辑与Agent.md)，不另定义自动幂等重放。
- 错误统一包含 stage、code、message、recovery。code 可用于定位和恢复操作，message 面向用户，provider 原始响应只在受控适配边界处理，不输出 Key/原始错误体。分类及可重试边界以 [校验与恢复](校验与恢复.md) 为准。
- AbortSignal 用于协作取消，应用先使当前任务失效，再取消网络/Worker/渲染；事务前后均复核有效任务与版本。底层晚返回不能提交或发起下一阶段。取消请求不删除已经成功提交的成果。

## 3. 图源与论文查询

| 查询职责 | 输入范围 | 输出内容 | 无数据与精度 |
|---|---|---|---|
| 浏览器存储概览 | 当前站点、读取请求身份，无项目内容写入 | estimate 的可用/不可用/失败、usage/quota 与读取时间；应用独立返回唯一 PDF 资产总字节/数量 | 估算不持久化为领域真值、不计入 Paper revision；未知值不转零，过期读取不得覆盖新状态 |
| 项目工作台状态 | projectId，当前工作底稿/当前稿/上一版的明确选择 | 已保存产物、当前任务、可用操作及原因 | 原因来自事实推导，不持久化第二份 canGenerate |
| 论文分析页面与进度 | Paper 身份/版本、文件/页范围 | 所有页的自动判断、人工覆盖、处理版本与来源预览；运行任务提供计数/排队/限流等待 | 已完成数量与运行状态分开；查询不启动处理 |
| Figure 目录 | Paper 身份/版本，可选 documentId/文件角色筛选与定位 | Figure/Panel 身份、缩略图所需来源、切分疑点 | 浏览状态归 UI；查询不把浏览变为确认 |
| 当前 Figure/Panel | Paper 身份/版本、figureId、可选 panelId | documentId、文件角色/名、原页 bbox、标签、当前切分和来源 | Panel 必须属于 Figure；旧稿读取自己的 Paper |
| 图注关联 | 同上 | 完整图注来源、关联片段、共享说明、来源页/区间、origin/status | 缺少精确引用时明示缺口；不把摘要伪装成原句 |
| 原文证据与发现 | Paper 身份/版本，来源或 Panel 范围 | 从 Claim → Evidence → Source 反查的原文与发现 | 多对多查询；无匹配不补造结论 |
| 讲稿/页面及 Panel 反向讲述 | Plan 或 Deck 的明确身份/版本与章节/页面选择 | 相应章节、讲稿、页面引用，以及 Panel sourceId 关联的全部讲述（含跨章） | 生成后的编辑读取 Current Deck，不回写已消费 Plan |

返回的文字与源图定位保持同一 Paper 版本。具体读取函数和 tool 名称优先复用现有入口；表中职责不是要求逐项新建 service 或目录。

## 4. 命令与阶段入口

| 入口/职责 | 核心输入与前提 | 成功结果与事务范围 | 失败与影响 |
|---|---|---|---|
| 保存/清除全局模型配置 | 当前设置基准、完整配置或明确清除 Key 意图；无运行模型任务 | settings 内原子提交；只清除 Key 时其余已保存字段保留 | 失败保留旧配置与草稿；不改变 Paper/Deck revision，不自动启动任务 |
| 测试配置 / 检查应用能力 | 当前设置草稿、检查种类、请求身份与 AbortSignal | 只返回绑定当前配置的连接/逐项能力结果；不发送项目内容 | 经共享调度器，参数不支持明确失败，不回退协议/降档；字段变化/取消后不接受迟到结果 |
| 创建项目 | 具名参数：主论文文件、可选补充文件、项目名称、汇报要求；各文件含 Blob 与文件信息 | 全部已选 PDF 资源、document 记录、空 Paper、Project 同事务 | 恰好一主至多一补；任一文件失败不留半项目；保存与开始分析是两个显式意图 |
| 保存汇报要求 | 项目基准与新的 instruction 文本，可为空 | 更新 Project.preferences.instruction；新建、分析左栏及公共设置共用入口 | 不改变 Paper/图核对版本；只取消依赖旧偏好的生成任务或使候选失效，保留现有讲稿/PPT，失败保留输入 |
| preparePaper() | 项目、当前底稿基准、任务/取消信号 | 按 documentId 解析全部已上传材料，逐完整阶段保存全文、图源、证据及跨文件关联 | 已完成阶段可恢复；首次结束停在论文分析页，等用户手动进入图源核对 |
| 设置/恢复图源页选择 | Paper 基准、documentId、页码、预期 selection revision、include/exclude/恢复自动 | 保存人工覆盖及影响；活动分析中纳入局部队列，就绪后补选授权局部处理；已暂停则只标待处理 | 有图源/引用的排除先返回影响候选；迟到结果不得覆盖人工选择，保护旧稿 |
| 进入图源核对 | 用户点击、当前工作底稿，无未保存冲突且分析就绪 | 只改变查看位置；不确认切分、不自动生成、不增加 checkpoint | 由应用统一查询与执行时复核；页选择改变/处理未完成则拒绝并定位 |
| 保存图源修改 | 图源基准、当前 Figure、有限几何/补删/标签命令 | 工作 Paper 图源一次提交，维护确认失效与依赖标记 | 非法框不写入，保存失败保留草稿；保护冻结旧稿 |
| 应用图注关联 | Panel 稳定 ID、Paper 基准、所选 caption 来源及专属/共享角色 | 一次 Paper revision 和 Undo；保存手动 origin 与关联状态 | 校验来源所属、原文区间和去重；不改切分 revision |
| 重新识别当前 Figure | 基准、当前图源与局部材料、任务 | 只形成与当前框对照的候选 | 原人工结果不变；应用时重查基准 |
| confirmFigureReview() | 图源已保存、预期 Paper 与切分 revision | 保存对该切分版本的整体确认 | 与浏览计数无关；重复/过期确认不可授权旧任务 |
| generatePresentation() | 用户进入幻灯片、已保存大纲/讲稿、核对及成果基准有效、新任务 | 调用页面规划与构建，步骤内自动完成 | 不隐式重生成讲稿；内部问题有限修复，不转嫁字段 |
| prepareOutline() | 用户确认切分并启动、完整论文底稿、关联已处理、汇报要求 | 保存章节和完整讲稿，outline-ready，结束步骤任务 | 不按默认页数丢发现；未完成不推进 checkpoint |
| planSlides() | 已保存章节/讲稿及对应 Paper 基准 | 分配讲稿、来源、布局和页序，形成可校验计划 | 人工内容被影响时先形成变化候选 |
| buildPresentation() | 已保存的 ready Plan 和全部有效基准 | 严格按计划生成完整稿；首次保存 Current，重生成保留候选 | 不暗改页序/讲稿/来源；失败保留有效计划与旧稿 |
| 编辑计划/文稿 | 明确域和基准、有限章节/讲稿/页面命令 | OutlineSession 或 DeckSession 单一提交；联动归属和引用 | 草稿/ready 边界及同步规则见领域约束 |
| 应用提案/候选 | 候选身份、原基准、明确用户应用 | 重校验后一次事务提交相关成果/历史 | 过期、范围变化或已有草稿时拒绝，不强制应用 |
| 恢复上一版 | Project 与 Current/Previous 基准 | 原子交换，保留各稿自己的 Paper/讲稿 | 失效旧任务与会话，不改绑定科学内容 |
| 导出所选稿 | 已保存 Deck/Paper 版本、无阻断错误、取消信号 | 从稳定稿派生 PPTX 与备注/讲稿文件 | 导出失败不改稿；取消后不迟到触发下载 |

“确认切分并生成讲稿”由应用顺序执行保存图源、保存确认、启动大纲/讲稿生成；完成后不调用页面规划。“下一步：生成幻灯片”先保存正文，再启动该步骤任务。确认成功而后续请求失败时保留已确认版本和已保存成果，提供恢复入口；不可把网络调用包进数据库事务。各阶段完整产物、下一动作与事务边界只在 [工作流与存储](工作流与存储.md) 维护。

## 5. 外部能力适配器

| 能力 | 应用提供 | 适配器返回 | 限制 |
|---|---|---|---|
| PDF 解析/渲染 | 明确 documentId 及其固定 PDF 资源、页/旋转、明确尺寸与裁切范围、取消信号 | 可定位文本/页信息或可释放图像资源 | 不维护领域版本；源矩形转换和旋转一致 |
| 请求调度 | 供应商配置身份、限额桶、任务、取消信号、请求预算 | 排队/限流等待/派发与最终结果 | 所有模型路径共用限额；不输出凭据，等待不等于完成 |
| 图像 Worker | 像素数据、尺寸、有限算法参数、任务/版本 | 候选边界或取消/错误 | 不访问数据库，不覆盖人工框，不让预览像素缓冲失效 |
| 模型结构化调用 | 当前阶段所需原文/图像、Prompt、Schema、取消信号 | 该阶段完整候选及有限进度 | 不宣称模型已校验业务，不交回自由执行代码 |
| Pi Agent | 模型配置、当前工具集合、可见上下文、取消/事件接线 | 可见事件、读结果或受控提案 | runtime 归 infrastructure；工具权限和提交归 app |
| 原子持久化 | 已验证候选、预期基准、明确跨 store 操作 | 成功保存的新快照或错误 | 事务内重读基准；失败全体回滚，不串接多个 save 冒充原子性 |
| PPTX 输出 | 已校验 Deck/Paper、共享布局及图像资源、取消信号 | 可下载文件与必要错误 | 图像/备注由保存稿派生；资源容量、分批与释放见渲染规范 |

以上为职责契约；只为实际调用建立窄接口。不能因此增加通用 DI、任务引擎、可执行脚本或第二套 PDF/模型/存储流程。

## 6. 接口验证边界

查询无副作用、命令范围/基准、提交失败不推进状态、取消与迟到响应、冻结 Paper、关联编辑与 Undo，是本接口的必要风险。纯规则在领域测试，流程用有限替身，真实 PDF/IndexedDB/PPTX 在适配器检查，UI 沿既有主链检查。详细范围与是否通过由 [验证策略](../execution/验证策略.md) 和阶段记录维护，本文件不重复声称实现验收。
