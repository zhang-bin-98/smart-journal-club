# 数据约束与领域不变量

> v0.5 目标设计，应用尚未实施；当前状态见 [执行目录](../execution/README.md)。

本文件维护数据合法性及领域不变量，类型定义只在 [数据模型](数据模型.md) 维护。提交时机和跨 store 原子性见 [工作流与存储](工作流与存储.md)。

### 图源页选择与就绪

FigurePageSelection 按 documentId + pageNumber 唯一，引用本 Paper 的页；pdf-parsed 后每页一项，自动扫描未结束为 pending，不能伪造为 not-detected。有效选择由 manualOverride 优先、其次 automatic=detected 派生，不另外保存 selected 真值。人工 exclude 不删除该页的 TextBlock、方法或图注，不等于 CoverageOmission。

每项 revision 为正整数，自动判断或人工覆盖改变时递增；相同意图不重复变化。processedRevision 只能来自该版本完整图源处理、必要依赖刷新与持久化成功，且不大于 revision；不能以发出请求或渲染缩略图代替完成。自动阴性/人工排除页无相关产物时可在合法提交后确认无需图处理；已有图源或引用时，须显式应用影响处理并完成必要刷新后才能标记该 revision 已处理。

进入图源核对由应用查询推导：全部文件解析与图页发现完成、所有选择 revision 已处理、全文理解和必要关联完成且无未保存冲突/失败。checkpoint 单独不足以证明就绪；新增待处理项不会抹掉已有完整阶段。该门槛不是逐页 user confirmed，也不新增 UI-only checkpoint。

人工覆盖优先于旧任务；晚到结果必须重查页 selection revision 和 Paper 基准。页级变化遵循工作 Paper 复制与旧稿冻结规则；影响 Figure 集合/内容时使整体核对失效。先按来源反查跨页 Figure 与引用，只处理受影响单元，不把同页码另一文件的图一并删除。取消有成果页先给影响候选，不静默破坏讲稿或已保存 Deck。

### 完整分析单元与恢复

analysisUnits 只登记已校验并保存的完整结果，其正文/图源/证据存于 Paper 对应集合，不复制模型响应或科学内容。阶段与目标共同确定逻辑单元：text/figure-discovery/figure-location 对应页，panel-analysis 对应图块，evidence 可对应受影响图块或全文汇总；稳定 id 不含执行顺序。inputKey 由应用对该单元实际输入和依赖生成，不包含无关页的提交版本、运行任务 ID 或凭据。每个单元只保留当前完整记录，输入改变后旧记录不能计入完成；未变且已保存结果可跨刷新复用。

结果和完成记录必须同事务提交；失败/超时/取消/无效输出不登记完成，不保存流式半结果。no-figure-located 只用于成功的 figure-location：保留可定位原页和识别缺口，允许进入图源核对人工补整图，不伪造 Figure。整阶段就绪仍检查所有必需单元和依赖，不以完成一页推进 checkpoint。已保存的无图处理结果不等于用户确认该页确实无图。

### 项目、全文与来源

Project.paperId 指向当前工作底稿，Deck.paperId 指向该稿的证据版本；两者在编辑上游期间可不同，但必须属于同一 Project 和固定的论文文件集合。Project 名称独立于原标题；用户重命名同事务设置 nameIsCustom，后续自动补标题不得覆盖。

Paper.documents 是文件归属的唯一记录，首版恰好一份 primary，可有零或一份 supplement；每份文档有稳定 id、文件名和所属 pdfAssetId，Project 不重复保存单一 pdfAssetId。两份文件属于同一篇论文，不是两个项目；创建后文件集合固定，不开放替换/追加文件来改变既有论文依据。创建前允许更换或移除补充文件，后续变更材料使用新项目。

所有页、TextBlock、SourceReference 必须带有效 documentId；页唯一键为 documentId + pageNumber。Source 的 textSpan 指向相同文件和页的 TextBlock；Figure 是逻辑身份，regions 按顺序保存一个或多个单页图块；每个图块的 sourceId 定位具体文件和页，Panel 必须与所属图块同文件同页，bbox 按该 PDF 的尺寸解释。来源 ID 在整个 Paper 内唯一，两份 PDF 即使页码、图号相同也不能合并身份。来源文件角色与原图标签保留，supplement 文件角色不自动决定汇报 track；正文可以引用补充材料的证据。

全文以 TextBlock 为唯一文本载体，按原页保存阅读顺序、标题、段落、图注与表格内容，不只保留摘要。页记录保留尺寸和 blockIds，不再维护可独立修改的第二份 page.text。原句通过 blockId 与字符串区间定位，start/end 采用 JavaScript UTF-16 半开区间；需非空、不越块且文件与页码一致。跨段/跨页或跨文件证据使用多个 Source，不把不同页拼为虚假单页来源。textQuote 若存在必须对应原文片段；旧稿只有页级短引用时可保留并明确精度，不编造字符级几何。

FigureRegion/Panel 通过 SourceReference 持有页码和 bbox，不复制坐标。BBox 基于 PDF.js 应用原页旋转后的整页，左上为原点、归一化 x/y/width/height；所有值有限、宽高大于零、起点在页内且终点不越页。局部高清图中的像素框须经同一几何函数映射回整页，不能把 Figure 局部坐标当页坐标。图源必须有 bbox，Panel 与所属 FigureRegion 同文件同页且范围包含于该图块可读范围；手工调整导致冲突时以可视化方式修正/扩展整图，不静默切掉 Panel。

Figure.regions 非空，region ID 和 Panel ID 在本 Paper 内稳定唯一；同图号不能自动合并不同 Figure。人工“添加 Figure”创建独立身份及首个图块，“添加跨页图块”显式归入所选 Figure；不改变其他图块、Panel 或图注。单图允许 panels 为空并直接使用图块，不能以空 Panel 集合阻断整体确认。一个 Panel 仍是单页矩形；跨页科学内容通过多个图块/Panel 表达，图注独立跨页关联。

共享图例允许 Panel bbox 相交；不得以零重叠、L 形归属或矩形网格作为科学正确性的硬规则。保留原像素，不引入擦除、mask 或多边形输出契约。

### 论文底稿与证据关系

Claim → Evidence → Source 是唯一持久化方向；Source 可定位原文、图注或 Panel。一个 Evidence 可关联多个来源，多个 Claim 可共用 Evidence；反向“这句/这个 Panel 属于哪个发现”由查询计算，不再重复存反向列表。对每个可提取发现保留观察、关键实验条件及来源，区分作者观察、解释与可支持强度。字段合法不代表科学解释真实。

Paper 不含 slideBudget、讲稿或主线/补充标签。研究类型是事实描述，不是路由枚举或用户确认门槛；研究设计、对照与证据强度仍需据原文识别；汇报重点、时长或页数不得减少全文提取。策略在已有理解调用中选取默认建议，无法确定时 general，不能改变论文事实或支持范围。故事点是文章组织，不规定 PPT 顺序；无依据主题为空，遗漏或不确定关联给出可定位问题。

分析由全文解析、整图/Panel 处理和基于原文的证据整理组成，模型临时输出先校验再由应用映射 ID。不以 Figure 图形描述独立推断结果方向。下游上下文按 Claim/Evidence 取回原文片段、图注和所选裁图，必要时带相关段落；不能只传压缩摘要，也不默认传全篇 PDF。不引入向量数据库作为单篇论文的前置条件。

figureReview.revision 只随切分身份、标签、几何变化增加；确认绑定该 revision，两项确认字段同时存在且匹配才有效。科学关联重算增加 Paper.revision，但不冒充用户重新确认几何。pendingEvidenceFigureIds 保存因补删/改标签而需刷新关联的 Figure，保存与取消可恢复；只是边界变化且身份不变时无需重算科学解释。系统完成相应原文/证据整理后同事务清除标记，未完成前不能把旧关联用于新的规划。无依据的关系可保留明确缺口，不伪造完成；模型请求失败则继续保留待处理标记。确认只表示切分经过用户核对，不能命名为“论文事实已验证”。

automaticBaseline 保存当前完整自动识别的图身份与图源快照，仅用于“恢复自动结果”，不是第二个可写来源；不包含全文或模型响应。geometryOrigin/labelOrigin 用于保护人工调整，不表示科研置信度。重新识别候选暂不改 baseline 或人工结果，用户明确应用后才更新相应基线与当前来源。

### 大纲、演讲稿与文稿

sections 定义讲述章节顺序，slides 独立定义展示页序，每页必须归属有效章节；页序可以跨章节调整，不据展示位置反推章节或主线/补充身份。track 与 kind 独立，初稿主线先形成完整故事，补充默认置后；编辑可任意调序。标签变化不改顺序，排序不改标签；论文附图身份与汇报标签无关。Claim 的主线/补充归属从引用它的讲述段落所属章节推导，不能重复维护互相冲突的分类字段。

大纲与演讲稿先生成并供用户编辑，用户进入幻灯片步骤后才规划页面。SpeechParagraph 持有稳定段落身份、章节、讲述目的和有序 segmentIds；SpeechSegment 通过 paragraphId 归属唯一段落，正文只存 segment.text。两侧归属必须一致且每个片段恰好属于一个段落；段落正文、Claim 和来源集合从片段按顺序派生。分页可按完整句意细分片段，但保留 paragraphId、正文次序及来源；只有用户主动拆分/合并讲述才改变段落身份或边界。每个 segment 最多分配给一页，一页可含多个段落甚至不同章节的片段。Slide.sectionId 表示页面展示归属，跨章合页/移页不改变段落的章节；显式移动讲述段落才改变其 sectionId。讲稿文本只存 speech，不在 Slide 或导出 notes 再维护一份可编辑副本；本页讲稿按 speechIds 组合，写入 PPTX 备注时派生。拆分片段保留原片段身份用于保留部分，新部分分配新 ID，同批更新段落片段顺序和页分配；不能按页码或数组下标重建既有身份。更改分配、移动页面只维护必要引用，作为同一 revision。删页只移除其分配，讲稿片段保留为未分配，系统提供重新安排；不自动记为省略。

outline-ready 表示章节与完整讲稿已保存，slides 可为空；deck-plan-ready 表示页面已分配，所有需要讲述的片段均有有效页面。draft 可以保留未完成的讲述/页面分配；ready 是应用校验完成的构建就绪状态，不是人工确认，模型不能自行设置。用户编辑 ready 后回到 draft，在用户启动对应步骤时重新验证就绪；不新增 confirmed/confirmedAt；进入下一步是一次用户操作授权，与 ready 校验分开。

分页后返回大纲仍展示原段落，不能把每个片段显示为新增段落。段落顺序独立于展示页序；跨页复用 Panel 不复制讲稿文本。手工讲稿编辑保存后，备注按最新片段确定性派生；不自动改写页面标题、正文或图组。结论/图证据变化可给页面更新建议并按用户请求形成候选；仅因讲稿版本变化不能阻止导出。非法重复分配、引用失效、无法正确生成备注是阻断错误；合法未分配片段、建议重写过渡或页面属于提醒。

目的、take-home 与讲稿职责不同：purpose 解释页的作用，message 是屏幕 take-home，speech 承担完整口头表达，不用章节目的冒充讲稿。旧稿和手工空页可以无讲稿，不能迁移时编造；自动新稿的内容页须有相关讲述与来源。

用户从页面移除 Panel 仅解除该处展示关系，保留 Paper 原图与其他关联；未展示某图不自动记为遗漏 Claim。人工删减后的覆盖不足只作提醒，不阻止导出，也不要求用户补写理由；明确的发现舍弃操作可生成 omission 记录。版式溢出、无效引用与仍使用的必需资源缺失继续阻断导出。

默认覆盖 Paper.claims 的全部发现，允许在主线或补充表达，不以数量凑页。人工省略或用户明确压缩所需的省略写入 omissions，原因与来源于用户的要求可核对；模型自动漏掉的 Claim 不能伪造成 user omission。没有固定默认页数范围，targetSlides 仅表达用户要求，实际页数由 slides.length 派生；移除双重 slideBudget 维护和 focus 至少两页规则。

SpeechSegment.sourceIds 可引用多个 Panel 的稳定 sourceId，同一 sourceId 可被多个 SpeechSegment 引用；按当前 Plan/Deck 与 Paper 版本反查讲述，不保存第二套反向关联。移除本段关联不影响其他段落。拆分讲述保留来源供分别调整，合并讲述对来源去重取并集；关联多图不等于科学支持自动成立。

已选 Figure/Panel 来源由应用解析并自动合入有效来源集合；用户不维护引用登记。页面 Claim/Evidence 与图源应相符，不能以补全 ID 代替科学对应检查。计划与最终稿都保留 coverage 和讲稿，Deck 成功提交后由 Deck 承接最终结构，工作计划可消费删除。

每个 Figure 元素仅引用一个单页图块或一个 Panel，多图使用多个元素，同一 Panel 可在多页复用；组图不复制或改变源 Panel 身份，不把多图压成一个失去来源的位图。新图引用使用 regionId 或 panelId 二选一，均须属于 figureId；单图旧引用没有二者时只能解析唯一图块，多图块 Figure 不得默认取第一页。选“整个 Figure”时由应用展开为其各图块的独立元素，容量不足进入分页，不持久化跨页虚拟 bbox。来源来自本稿绑定 Paper。cropOverride 是整页坐标，仅覆盖当前元素，换引用清除覆盖，换布局保留。所有新对象严格白名单，不预留任意坐标、themeId、脚本或通用 JSON Patch。

### Figure legend 与 Panel 关联约束

完整图注仍以 TextBlock 为唯一原文载体。Figure.captionSourceIds 按阅读顺序引用 kind=caption 的 SourceReference 片段，覆盖该 Figure 可提取的完整图注；允许跨块/跨页拆为多个来源。旧 caption 字符串仅为旧稿只读兼容摘要，不能作为第二份可编辑原文，新分析以 captionSourceIds 为准。

Panel.captionAssociation.links 引用同一 Paper 中属于该 Figure 图注范围内的 caption Source；每项必须具有合法 textSpan，区间落在 Figure 完整图注的来源范围内。每个 sourceId 在一个关联集合中只能出现一次，role 区分专属说明与适用公共说明；多个 Panel 可复用同一个 sourceId，反向查询派生，不存反向副本。共享角色不是“所有 Panel 都适用”的推断。

origin 表示当前关联集合由自动生成还是用户明确应用；status=linked 仅表示关联已建立，不表示科学事实经过人工证明。无可靠关联使用空集合和 needs-review；旧稿缺关联字段时显示未建立精确关联，不编造片段。新分析应显式给出集合和状态。中文释义是可再生成的展示文本，不能替换 textSpan 所指原文或作为第二份事实。

边框移动只更新几何与切分版本，保留稳定 Panel ID 和图注关联。改标签保留原集合并标 needs-review；新增 Panel 由系统补充，删除 Panel 清理该 Panel 的关联但不删除图注正文或其他 Panel 的关联。重新分析先形成候选，不自动覆盖 origin=manual 的集合，包含用户明确应用的空集合。恢复或删除后通过单一提交入口维护版本、Undo 及冻结底稿保护。

手动应用图注关联增加 Paper.revision 并标记该图依赖的证据待刷新，但不修改切分几何版本、不新增逐条确认关卡。系统在后续规划前处理关联待刷新状态；未可靠建立的科学关系以缺口呈现，不能将用户选择图注当作模型发现的科学结论。
