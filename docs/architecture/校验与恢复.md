# 校验、错误与恢复

> v0.5 规格；实际交付与验收状态见 [执行目录](../execution/README.md)。

## 6. 校验与失败处理

Zod 负责形状白名单，普通函数负责引用与几何，不建通用校验框架。错误统一携带 stage、code、message、recovery，区分 PDF、模型认证/额度/限流/网络/无效输出、来源/布局、导出与存储失败；用户只看到必要产品信息。

| 类型 | 处理 |
|---|---|
| 非法 ID/跨项目引用/越界 bbox/错误 Panel 归属 | 进入系统定向修复或图源可视化调整，仍非法不得写入 |
| 成功处理图源页但未定位 Figure | 保留原页及识别缺口，允许进入图源核对手动添加 Figure；请求失败/无效输出不得冒充此结果 |
| 漏标签、疑似切断内容、共享图例困难 | 标记图核对疑点，保留原图，不自动断言科学正确 |
| 可派生来源登记、布局容量、章节和讲稿分配 | 程序维护；生成失败由内部定向修复/重新规划处理，不交给用户填字段 |
| 原文或必需图源缺失、模型不可用 | 保留成果、定位并提供重试/设置；不得下载缺失证据的半成品 |
| 未覆盖论文发现/用户主动舍弃图 | 自动生成时补齐或报告该单元未完成；人工编辑后的覆盖变化仅提醒，不阻断导出；明确舍弃发现才记录 omission，未展示某图不自动等于遗漏发现 |
| 讲稿修改但建议更新页面、合法未分配片段 | 仅提醒；备注从唯一正文自动派生，不因未重生成 PPT 阻断下载 |
| 非法重复分配、引用失效、无法正确生成备注 | 确定性同步错误，修复后才能导出；不能以语义建议冒充硬错误 |
| 内容或图组无法容纳、导出会裁断 | 必须修复版式、调整分页或由用户明确删减后重新校验；未解决不能下载 |
| 标题、叙事比例/顺序、过渡、重复表达 | 可定位建议，不阻止用户删页、保存或逐项要求确认 |
| 科学措辞或对应关系不确定 | 明确疑点与依据；用户确认切分不等于事实证明 |
| 论文页级分析输出截断 | 未填写最大输出时，首次用 16384，仅明确的 truncated 可提高到 24576 重试一次，与格式/引用修复共用一次机会；填写后首轮即用该上限，不越过配置扩容或在相同预算下自动重试截断。仍失败则定位文件/页并保留已保存单元；取消后不重试。全文汇总使用配置值或默认 24576，并沿用分批处理 |
| 上下文容量不足 | 发送前将输入估算与预留输出相加；超过有效上下文窗口报 context-budget，提示核对窗口或降低输出上限，不截短原文或保存半份结果。估算不代表供应商精确分词，填写配置也不证明服务支持该容量 |
| 临时请求限流 | 统一调度器等待并降低发送速率；遵循可读取且有效的 Retry-After，否则有抖动的指数退避；每个逻辑调用最多两次限流重试，累计退避最多 120 秒，超出则保存成果并给继续入口；参数为初始策略，需供应商验证 |
| 认证失败/额度耗尽/不可分类的 429 | 停止并提示设置或额度；不可将全部 429 盲目当作可恢复限流，不无限重试 |
| 过期版本、越权、重复请求或取消 | 拒绝提交，不改稳定成果或提供强制覆盖 |

提取完整性与汇报覆盖性分开：前者在全文解析/理解验收中核对原文块、图注、Figure/Panel 的处理范围及未建立关系的位置，未引用某段不自动等于遗漏发现；后者依据 Paper.claims 到章节/讲稿/页面的关联与用户省略计算。覆盖全部已提取 Claim 不证明全文没有漏提取。应用向用户呈现具体缺口与原文位置，不给出无依据的“全文 100% 理解”或科学置信度；真实三篇论文检查仍是必要证据。

validatePlanNarrative 与 validateDeckNarrative 仍为两个薄入口，共享确定性 helper，不使用混合 Plan|Deck validator。叙事建议按主线计算，补充在后不触发“最后必须 Take-home”硬错误；移除固定背景/结果比例和 focus 页数作为门槛的旧规则。

数据结构与引用始终有效，草稿可缺完整讲述分配，ready 才满足完整页面与讲稿覆盖。自动生成至少一页、内容页有讲述和依据；用户创建的空页、删空与旧稿允许保存，零页禁用导出。迁移后缺讲稿不是历史稿的阻断项。任何字段合法都不能证明科研事实。

构建合同 validateBuiltDeckAgainstPlan(deck, readyPlan) 独立于叙事检查：核对 plan/Paper revision、页面 ID/顺序/章节/track/kind、title/purpose/message、layout、Claim/Source、Figure/Panel 与 speech 分配和正文。Build 只填充指定元素，不暗改讲稿或图源；失配拒绝提交并保留计划，按受影响单元修复。必要重规划先形成新版本，再重新核验人工改动边界。

硬错误仍阻止依赖它的导出，普通警告无需逐项点击确认。检查作为编辑工作台内的能力，在编辑提交后更新并于导出前自动核对，不要求进入独立页面。检查结果由当前快照计算，不持久化第二套问题真值；每条有稳定 code 和定位，重复点击可再次定位，解决后移除说明，无对象的全局问题指向明确入口而非虚构页码。
